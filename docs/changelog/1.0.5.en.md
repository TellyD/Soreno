# Soreno 1.0.5

## What’s new

- `Ctrl+Shift+W` (`Cmd+W` on macOS) closes the active session tab, even when the terminal has focus. A pinned tab is not closed. On macOS, **Close Tab** replaces **Close Window** in the menu, so `Cmd+W` no longer quits the app.
- An agent can edit the title or description of the issue linked to its session, local or Linear, when you explicitly ask it to. The shown issue is reloaded, and a description being typed in Soreno is not replaced.
- From a project group’s overview, the `@` of Claude Code, Codex, Pi and OMP suggests files from the group’s repositories, under `<repository>/…`. Soreno places a link to each repository in the group’s folder for this.

## Fixes

- The right panel remembers for each session whether it shows its issue or the project tools.
- In the editor’s live preview, list bullets, checkboxes and numbers are aligned, and nested lists start under the parent text. A heading or block right after the previous block, without a blank line, is spaced from it.
