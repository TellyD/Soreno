# Soreno 1.2.8

## What’s new

- A Linear issue can be assigned to a team member from its details, with the **Assignee** field. Cards and details show the assignee with their avatar, and comments show their author’s avatar.

## Fixes

- Closing the tab of an automation’s session no longer deletes it: the session stays available as long as the automation exists.
- A group overview’s agent is asked to name the group project an issue it creates concerns, and the issue is attached to that project. An unknown name makes the request fail, and the agent gets the list of possible projects.
