# Soreno 1.2.6

## Nouveautés

- Le bouton **Vue par priorités** du rail des projets range les sessions en deux sections : **À traiter**, avec d’abord les sessions qui attendent une réponse puis celles qui ont un tour non lu, et **En cours** pour les autres sessions actives. La vue choisie est mémorisée.

## Changements

- Les boutons **Tout replier** et **Tout déplier** du rail s’appliquent aux projets comme aux groupes.
- Les fonds de survol sont plus discrets dans le thème clair.

## Corrections

- Dans **Design**, une image collée ou déposée reste dans le brouillon jusqu’à l’envoi, même si l’agent est relancé entre-temps. Un fichier qui n’est ni PNG, ni JPEG, ni GIF, ni WebP est refusé avec un message.
