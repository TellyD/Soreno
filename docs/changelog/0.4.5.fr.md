# Soreno 0.4.5

## Nouveautés

### Chat : ajouter du contexte avec @

Dans le chat, tapez `@` pour mentionner un fichier ou un dossier du projet : Soreno propose les chemins correspondants, joint leur contenu au message et permet d’en afficher l’aperçu avant l’envoi.

### Trier les fichiers modifiés

Dans Changements, le menu **Trier les fichiers** ordonne chaque groupe **Par chemin** (par défaut), **Plus modifiés d’abord** ou **Moins modifiés d’abord**, selon le nombre de lignes ajoutées et supprimées. Les fichiers binaires et non suivis restent en fin de groupe, et les flèches précédent/suivant suivent cet ordre. Le choix est mémorisé et s’applique aussi au diff des groupes de projets.

## Changements

- Le chat est signalé comme expérimental et n’est plus proposé par défaut : activez-le dans **Réglages** > **Agents**. Si vous avez déjà modifié vos réglages depuis la 0.4.0, votre choix d’agents reste inchangé.
- L’agent **worker** proposé par défaut au chat utilise le modèle GPT-6.1 Sol.

## Corrections

- Un projet SSH déconnecté, ou non connecté au lancement de Soreno, garde son regroupement de worktrees dans la liste des projets.
- Le chat ne perd plus un message envoyé au moment où l’étape démarre, ne coupe plus une réponse en cours quand une erreur s’affiche, et signale comme non envoyés les messages en attente d’une session redémarrée.
- Dans un projet SSH, les commandes du chat s’exécutent bien dans le dossier du projet, même si le profil de connexion du serveur change de dossier.
- Maj+Tab quitte les suggestions de commandes `/` du chat.
