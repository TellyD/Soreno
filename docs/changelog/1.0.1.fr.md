# Soreno 1.0.1

## Nouveautés

- `Ctrl+,` (`Cmd+,` sur macOS) ouvre les paramètres, même quand le terminal a le focus. Sur macOS, le menu de l’application propose aussi **Settings…**.

## Changements

- Dans les paramètres, les notes chiffrées ont leur propre section **Notes**.
- Dans les paramètres, la liste des commandes OMP et les listes de skills sont repliées par défaut ; **Afficher les commandes** déplie celle des commandes.
- Les onglets de sessions défilent horizontalement avec la molette de la souris.

## Corrections

- Dans un diff, la mise en évidence des caractères modifiés compare désormais les lignes qui se correspondent, au lieu de les comparer dans l’ordre.
- Une opération Git qui arrête les sessions d’un projet n’empêche plus de démarrer celles des autres projets.
- Un projet ou un worktree dont une session a encore une automatisation, même en pause, ne peut plus être supprimé : un message explique qu’il faut d’abord la supprimer depuis la vue **Automatisations**.
