# Soreno 1.0.2

## What’s new

### A session’s issue in the right panel

An agent session linked to a Kanban issue shows an **Issue SOR-N** button next to **Project tools**. The issue then takes the place of the project tools and can be edited as on the board: status, priority, project, labels, description, comments, sub-issues. Changes show up on the board right away, and **Open in Kanban** shows the issue there. The `Ctrl+Alt+K` shortcut (`Cmd+Option+K` on macOS) opens or closes this panel, even when the terminal has focus.

- A session without an issue offers **Link an issue** instead: pick an open issue without an agent, or **Create an issue**. The issue moves to In Progress, and the agent receives its title, description and the report instruction, as if it had been started from it.
- **Unlink from this session** removes the link after confirmation. The issue keeps its status and comments, and the agent is told.

### Kanban issues in Chat (OMP) sessions

Like terminal agents, a Kanban issue can start a Chat (OMP) session or be linked to one. The issue’s prompt is sent as the first message, with its images, and the end-of-turn report is posted on the issue. The conversation shows this report without its tags.

## Changes

- The **Skills** section of the settings is removed, along with updating and deleting skills from Soreno.
- In the Kanban list, search and the create button stay visible while scrolling.

## Fixes

- When a dialog opened with the mouse closes, the element that opened it no longer shows the keyboard focus ring. The ring comes back when the dialog was opened from the keyboard.
