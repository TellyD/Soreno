# Soreno 1.3.2

## Nouveautés

- Une issue du Kanban peut cibler la vue d’ensemble d’un groupe jamais ouverte : les vues d’ensemble sont proposées en tête des projets, et Soreno prépare celle choisie avant d’y rattacher l’issue ou d’y démarrer son agent.

## Changements

- Les listes de projets des formulaires (Kanban, Design, automatisations, connexion SSH) sont triées par nom.
- La fenêtre d’un groupe affiche les projets d’une seule machine à la fois et n’enregistre que ceux-là, pour que tous les projets d’un groupe restent sur la même machine.
- Les demandes d’issues en attente d’un agent sont traitées à la suite, sans attendre entre chacune.

## Corrections

- Un commentaire non envoyé ou une description non enregistrée sont conservés quand on ferme puis rouvre une issue, y compris si leur envoi échoue après la fermeture.
- Dans le formulaire d’un projet SSH, saisir un hôte qui correspond à un projet existant ne referme plus le champ en cours de saisie, et **Modifier la connexion** rouvre les détails de connexion.
- Dans **Design**, le thème sombre n’affiche plus de flash blanc quand un cadre réapparaît.
