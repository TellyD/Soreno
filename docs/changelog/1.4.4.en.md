# Soreno 1.4.4

## What’s new

- An issue’s header has a **Copy git branch name** button, which copies the issue’s branch name and confirms it with a notification.

## Changes

- Chat (OMP) is adapted to OMP 19.2: an `ask` form whose answer breaks a rule can still be sent, with the error still flagged. An empty required field is only flagged once focus has moved past it.

## Fixes

- Renaming a local issue updates its branch name right away, along with the other views showing it.
