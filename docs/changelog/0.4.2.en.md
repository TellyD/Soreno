# Soreno 0.4.2

## Changes

- AI commit review (**Review commit** in the Git history) is removed. The **Git** card in the **AI** settings now only sets the model for commit messages.
- In the activity bar, **Projects** now uses a house icon.

## Fixes

- When a Linear issue’s description is too long for the agent’s launch message, the full issue is attached as a file with all its images: the agent no longer loses the end of the description or the images in it.
- A Codex session title no longer keeps the truncated project name (“...”) that Codex adds when the folder name is long.
