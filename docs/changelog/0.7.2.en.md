# Soreno 0.7.2

## What’s new

- The mobile page now also shows **Chat (OMP)** sessions from SSH servers: you can follow their conversation and send them messages from your phone, as with terminal sessions.
- In Chat (OMP), images in the conversation and attachments in the composer show as thumbnails; clicking one opens it full size.

## Changes

- The **Mobile** button in the status bar is shown again.
- Mermaid diagrams are drawn by a lighter engine, still in the light or dark theme’s colors.

## Fixes

- Over SSH, commit message generation now accepts a root `AGENTS.md` that is a link to a file in the repository, as it does locally, instead of refusing it; a link pointing outside the repository is still refused.
