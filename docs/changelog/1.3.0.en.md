# Soreno 1.3.0

## What’s new

- A session linked to an issue takes the issue’s title in its tab, instead of the launcher name or the title guessed by Claude Code and Codex. A name set by hand still wins, and renaming a local issue renames its session.
- A terminal session restored but not started shows **This session is not running.**, with **Start**, or **Resume the conversation** when a conversation exists.
- The **Priority view** button shows the number of sessions to handle, up to 9+, in the color of the most urgent one.

## Changes

- In notes, the last lines can scroll up to the middle of the screen.

## Fixes

- Starting a local or WSL session no longer waits for a project save to finish.
- A conversation that is starting and a WSL group folder are no longer affected by a simultaneous project change.
