# Soreno 0.7.3

## Changes

- In the Git panel, **Pull** and **Push** are always shown in the file bar, with the number of incoming or outgoing commits when it isn’t zero; the button to use takes the primary color, **Pull** first if the branch has diverged. **Pull with rebase** and the **Remote repository** choice stay in the **More actions** menu.
- In Chat (OMP), **Hide the finished tasks** closes the task list once everything is done; it comes back as soon as it changes.
- In Chat (OMP), only permission requests keep an icon, above the composer.

## Fixes

- In Chat (OMP), a long queued message no longer overflows the composer.
