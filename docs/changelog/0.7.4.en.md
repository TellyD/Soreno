# Soreno 0.7.4

## Changes

- Mobile access is paused while its security is strengthened: no phone can reach a server anymore, but pairings are kept. The **Mobile** button only appears on a server where the service is already installed, and only lets you disable it.
- In Chat (OMP), `/grill` asks its questions in rounds: each round gathers the decisions that can already be made, and OMP settles obvious choices itself, saying so. When several questions arrive together, clicking the chosen option again leaves one question unanswered without losing the others.
- In Chat (OMP), an attached image inserts its `[Image #N]` marker at the cursor, shown as a chip in the composer: the message says where each image belongs. Removing an image removes its marker and renumbers the following ones.

## Fixes

- A command sent to an agent right after its session ends no longer produces an error: only the end of the session is reported.
- An image thumbnail preview no longer overflows the composer’s width.
