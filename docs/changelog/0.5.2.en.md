# Soreno 0.5.2

## Changes

- In a Git diff, an image preview shows its dimensions and file size, and the size difference between the two versions. Both versions are shown in a frame of the same size, so a resize stands out at a glance; an added or deleted image is marked **Added** or **Deleted**.

## Fixes

- Phone pairing works in Safari (iPhone, iPad, Mac): Safari can’t store the phone’s key as is, so it is now kept encrypted there.
