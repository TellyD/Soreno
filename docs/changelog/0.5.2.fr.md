# Soreno 0.5.2

## Changements

- Dans un diff Git, l’aperçu d’une image indique ses dimensions et son poids, et l’écart de poids entre les deux versions. Les deux versions s’affichent dans un cadre de même taille, pour qu’un redimensionnement se voie d’un coup d’œil ; une image ajoutée ou supprimée est marquée **Ajouté** ou **Supprimé**.

## Corrections

- L’appairage du téléphone fonctionne dans Safari (iPhone, iPad, Mac) : Safari ne sait pas enregistrer la clé du téléphone telle quelle, elle y est désormais conservée chiffrée.
