# Soreno 1.2.5

## Nouveautés

- Dans **Design**, la barre de prompt accepte des images, collées ou déposées. Chacune apparaît dans le texte sous la forme `[Image #N]`, avec une miniature, et l’agent reçoit le chemin du fichier à cet endroit.
- L’éditeur de fichiers a un bouton **Retour à la ligne**, mémorisé d’une session à l’autre.

## Corrections

- Un groupe de projets replié affiche l’activité des sessions de ses projets.
- Un pull avec rebase annulé à cause d’un conflit est expliqué dans la langue de l’interface : la branche est intacte, et le conflit se résout dans un terminal avec `git rebase`.
