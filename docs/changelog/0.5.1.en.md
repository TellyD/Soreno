# Soreno 0.5.1

## Fixes

- Mobile access can now be enabled on servers without systemd, such as Gitpod containers and devcontainers, where activation used to fail. The service runs in the background there, and each SSH session Soreno starts relaunches it if it stopped; the **Mobile** dialog shows **Update required** while it is stopped.
- On a server with systemd, activation no longer fails when keeping the service running after logout is already enabled. If it isn’t and the server refuses to enable it for your account, an administrator only needs to run `sudo loginctl enable-linger <account>` once.
