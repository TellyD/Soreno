# Soreno 0.7.9

## Nouveautés

### Sélection dans tout l’historique du terminal

Dans le terminal d’un agent, la sélection peut couvrir tout l’historique et reste en place quand vous faites défiler ou que l’agent redessine l’écran. Glisser au-delà du bord haut ou bas fait défiler le terminal ; double clic sélectionne un mot, triple clic une ligne, Maj+clic étend la sélection. **Sélectionner tout** prend tout l’historique, et **Copier** copie exactement ce qui est sélectionné. Toute saisie efface la sélection.

### Services sous le terminal

Les services d’un projet s’ouvrent désormais dans un panneau sous le terminal, qui reste visible et utilisable. Le bouton **Services** de la barre d’état, avec le nombre de services lancés, ou `Ctrl+Alt+J` (`Cmd+Option+J` sur macOS) l’ouvre et le ferme ; **Échap** le referme. Sa hauteur se règle par sa bordure haute, et son état est retenu pour chaque projet.

## Changements

- Dans **Changements**, le menu contextuel d’un fichier propose **Ouvrir le fichier**.
- L’option **Afficher toutes les lignes** du diff est retenue d’un fichier à l’autre et après un redémarrage.
- Le worktree actif est marqué en couleur principale dans la liste des projets.
- Le panneau **Usage** n’affiche plus l’abonnement à côté de l’adresse e-mail de chaque compte.
- Retouches visuelles : carte sélectionnée de l’usage avec un contour au lieu d’un fond, actions Git d’un groupe de projets regroupées.
