# Soreno 0.1.9

## Nouveautés

### Redirection de ports SSH

Le nouveau bouton **Ports**, dans la barre d’état d’un projet SSH, permet d’ouvrir dans votre navigateur un service qui tourne sur le serveur distant (serveur de développement, application web…).

- Saisissez un ou plusieurs ports, ou une plage comme `8088:8095`.
- Si un port est déjà utilisé sur votre machine, Soreno en choisit un autre et vous l’indique.
- **Ouvrir** lance le service dans le navigateur ; **Tout arrêter** coupe toutes les redirections.
- Les redirections s’arrêtent quand vous déconnectez le projet ou fermez Soreno.

### Sessions SSH conservées après fermeture

Fermer Soreno n’arrête plus vos sessions sur un serveur SSH : quand vous les rouvrez, vous retrouvez le terminal là où vous l’aviez laissé, agent compris. Pour terminer vraiment une session, utilisez **Arrêter**.

Pour cela, Soreno installe automatiquement un petit utilitaire (`dtach`) dans `~/.cache/soreno` sur le serveur. Il ne demande pas de droits administrateur et fonctionne sur Linux et macOS, processeurs Intel/AMD comme ARM.

### Ouverture rapide de fichiers

`Ctrl+P` (ou `Cmd+P` sur macOS) ouvre une recherche de fichiers dans le projet. Il suffit de taper quelques lettres du nom. Les fichiers ignorés par Git n’apparaissent pas. Cela fonctionne aussi pour les projets WSL et SSH.

### Fusionner un worktree et le supprimer

Une nouvelle action, **Fusionner dans \<branche principale\> et supprimer**, termine le travail fait dans un worktree en une seule fois. Elle est disponible dans la vue **Branches** ou par clic droit sur le worktree dans la liste des projets.

- Les changements du worktree sont intégrés à la branche principale, puis le worktree et sa branche sont supprimés.
- En cas de conflit, la branche principale n’est pas touchée : résolvez le conflit dans le worktree, commitez, puis relancez l’action.
- Si le worktree ou le dépôt principal contient des modifications non commitées, Soreno vous indique lequel corriger.
- Si des sessions tournent dans le worktree, la confirmation les liste et Soreno les arrête avant de fusionner.

### Création rapide de worktree

Le bouton `+` d’un projet, dans la liste latérale, crée un worktree à partir de la branche courante. Le worktree apparaît tout de suite dans la liste.

### Plus de fichiers modifiables

L’explorateur de projet permet maintenant de modifier n’importe quel fichier texte, quelle que soit son extension.

## Corrections

- Après un changement de branche, la branche affichée dans la liste des projets se met à jour tout de suite.
- Une session ouverte dans un autre environnement (par exemple sur un serveur SSH) n’empêche plus de changer de branche sur un projet local.
- Si la suppression d’une branche échoue, vous pouvez maintenant réessayer.
- Le terminal SSH s’affiche correctement quand vous rouvrez une session.
- Les worktrees ne s’affichent plus brièvement avant de disparaître de la liste des projets.

## Interface

- La liste des projets montre plus clairement quelles branches et quels worktrees appartiennent à quel projet.
- La session sélectionnée ressort mieux dans la barre latérale.
- Les fenêtres de confirmation ont le même style partout.
- Les indicateurs de fichiers modifiés et les messages d’erreur du panneau Git sont plus lisibles.
- Le bouton d’ajout de projet reste visible en permanence.

## Traductions

- Les messages d’erreur sont maintenant affichés dans la langue choisie (français ou anglais) dans toute l’application : assistant, coffres, types de notes, agents, panneau Git, services et projets SSH.
