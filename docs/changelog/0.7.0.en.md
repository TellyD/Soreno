# Soreno 0.7.0

## What’s new

### Frame a topic with `/grill`

In Chat (OMP), `/grill <topic>` starts a guided framing: OMP explores the code, then asks its questions one at a time, each with a recommended option and its rationale, without changing any file. The **Framing** column gathers the decisions as you answer; you can answer freely, revisit a decision or ask for the summary with **Summarize**.

### HTML mockups in the chat

`/mockup <topic>`, or **Mock up** in the **Framing** column, asks OMP for an HTML mockup, shown in a preview at **Mobile**, **Tablet** or **Desktop** width. The arrows browse the conversation’s mockups, and **Copy HTML** copies one. Clicking an element of the mockup lets you comment on it to request a change. During a framing, **Mock up this question** illustrates each option of a question with a variant, so you can answer while looking at it.

### Side questions

`/btw <question>` asks OMP a side question, even during a step, without redirecting it or waiting. The answer streams into a panel above the composer, never into the thread; the panel lets you ask a follow-up or stop the question.

### Keyboard shortcuts

- **Settings** > **Shortcuts** lists Soreno’s shortcuts with your system’s keys; holding a combination highlights it in the list.
- `Ctrl+B` (`Cmd+B` on macOS) hides or shows the sidebar, without taking over bold in the editor or the terminal.
- `Ctrl+Alt+B` (`Cmd+Option+B` on macOS) hides or shows the Git panel, including from the terminal.

## Changes

- Diff options (**Unified** or **Split**, **Wrap lines**, file list visibility) are kept from one file to the next and after a restart. With the list hidden, the shown file’s actions (stage, discard, resolve) stay in the diff bar.
- After **Update OMP**, **See what’s new** shows what’s new in the new OMP version.
- **Settings** > **Agents** > **OMP chat commands** chooses the commands offered by the chat’s `/` menu.
- Code blocks in a known language are highlighted in conversations, the Kanban and release notes.
- Option descriptions in an OMP question render Markdown, without clickable links inside the buttons.
- A single-choice question is sent with **Answer** after picking the option, instead of going out on the first click.
- Generated commit messages use your Codex account’s default model when no model is chosen.

## Fixes

- In Chat (OMP), a lost SSH connection is reported as such, instead of an unexpected OMP stop.
- A session’s goal (`/goal`) shows correctly again after resuming a conversation.
- Over SSH, the temporary folders created when a session starts are removed when it ends, even if it was running without Soreno.
