# Soreno 1.2.2

## What’s new

- Soreno is also released as an `.rpm` package for Linux (Fedora 39 or later). On Fedora, prefer it to the AppImage, which bundles its own WebKitGTK stack.
- `.deb` and `.rpm` installs now update automatically, like the AppImage. Installing the update asks for the administrator password.

## Changes

- An agent started from an issue whose description is too long for the prompt no longer gets a truncated description: it is asked to read `issue.md` first, which holds the whole issue.

## Fixes

- In messages and conversations, a plain web address becomes a link without its trailing punctuation or an unmatched closing parenthesis.
