# Soreno 1.3.1

## Changes

- The **Priority view** button flags sessions to handle with a dot, in the color of the most urgent one, instead of a counter. Their number still shows on hover.

## Fixes

- In **Design**, a frame resized by hand keeps its size when the agent edits it, unless the agent explicitly changes the frame size.
- In **Design**, the dark theme no longer flashes white while frames load.
