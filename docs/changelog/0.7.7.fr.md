# Soreno 0.7.7

## Nouveautés

- **Soreno sous Linux :** la release publie une AppImage et un paquet `.deb` pour x86_64 (glibc 2.35 et WebKitGTK 4.1 au minimum, soit Ubuntu 22.04, Debian 12 ou plus récents). L’AppImage se met à jour automatiquement, comme les versions Windows et macOS.
- Sous Linux, les notifications des agents passent par le bureau (GNOME, KDE Plasma…) et un clic ouvre la session concernée ; le gestionnaire de tâches de KDE Plasma, Ubuntu Dock et Dash to Dock affichent le nombre de sessions qui vous attendent.
- Sous Linux, la clé d’API Linear est conservée dans le trousseau de la session (GNOME Keyring ou KWallet). Sans trousseau accessible, la connexion à Linear le signale au lieu d’oublier la clé au redémarrage.
- **Télécharger…**, dans le menu contextuel d’un fichier de l’onglet **Fichiers**, enregistre une copie du fichier à l’endroit choisi sur votre ordinateur, y compris depuis un projet WSL ou SSH (8 Mio au plus en SSH).

## Changements

- Le formulaire d’un projet n’annonce plus que la découverte WSL est indisponible sous macOS : WSL n’y est simplement pas proposé.
- L’onglet **URLs** des projets SSH est retiré.
- Retouches visuelles : nombre de commits à envoyer ou à recevoir affiché sans pastille dans le panneau Git, lignes repliées du diff sans marge.
