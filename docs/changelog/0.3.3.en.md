# Soreno 0.3.3

## Changes

- Git operations no longer ask you to stop open agent sessions: unstaging, committing, restoring, switching branches, initializing a folder, fetch, pull, push and clone run without interrupting them. An agent writing during the operation may leave files modified right after; refresh the Git panel if needed.
- You no longer need to stop the agent before **Mark resolved** on a conflict.
- **Merge into \<main branch\> and delete** only stops the sessions of the deleted worktree, as before. Sessions in other worktrees, projects or machines no longer block the merge.
- The “Sessions are running in this repository” and “Soreno could not reliably identify the repository used by an active session” errors are gone, including across local and WSL environments.
