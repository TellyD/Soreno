# Soreno 1.2.11

## What’s new

- In a project group’s Git panel, the **Pull requests** or **Merge requests** tab gathers the requests of every project in the group, newest first, and each row names its project. Actions apply to the request’s project.
- Each project in the rail has a **New session** button that opens the agent menu without going through the tabs.

## Fixes

- Dragging a project below a group’s last project can place it either inside the group or right after it, and the drop target follows the project header rather than the middle of its session list.
- An SSH project that is not connected yet connects before its worktrees are read, for example to quickly create a worktree.
- In the editor, a bullet line inside a quote keeps the quote’s indentation.
