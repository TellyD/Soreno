# Soreno 0.3.6

## What’s new

### Codex and Claude usage per account

Codex and Claude usage in the status bar is no longer limited to the local account: Soreno also reads the accounts signed in on your projects’ WSL distributions and SSH servers. An account found on several machines appears once, with the list of its sources. When several accounts are found, a counter shows it: click the usage to choose which account is displayed, with its email address and plan. Your choice is kept.

### Linear: issue images passed to the agent

When you start an agent on a Linear issue whose description contains images, Soreno downloads them and makes them available to the agent, locally, on WSL and over SSH. The agent can open them even though Linear only serves them with your API key. Up to 6 images per issue; the copies are deleted when the session stops.

## Changes

- The assistant now runs on Codex only: Cerebras is removed, along with the **Provider** selector in **Settings** > **Assistant**. If Cerebras was selected, Soreno switches back to Codex automatically, keeping your other settings.

## Fixes

- On macOS, Soreno no longer asks for keychain access on every launch to read Claude usage, even after **Always Allow**, and reads the Linear API key only once per session.
