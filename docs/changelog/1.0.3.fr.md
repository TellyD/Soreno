# Soreno 1.0.3

## Nouveautés

### Issues du Kanban dans le panneau latéral

Dans le Kanban, une issue s’ouvre dans le panneau de droite, à côté du tableau, au lieu de remplacer le tableau. Les raccourcis du panneau Git s’y appliquent : `Ctrl+Alt+B` (`Cmd+Option+B` sur macOS) masque ou affiche l’issue, et `Ctrl+Maj+M` (`Cmd+Maj+M` sur macOS) l’agrandit ou revient au tableau. Une issue Linear d’une autre équipe s’affiche avec cette équipe.

### Commandes slash et images dans l’éditeur

- Le menu des commandes `/` est organisé en sections, avec une icône par commande, dans l’ordre de la barre d’outils.
- Une image seule sur sa ligne reste affichée quand le curseur s’y trouve. Les flèches passent par-dessus sa source, et une saisie ou un collage à côté ouvre un nouveau paragraphe.

## Changements

- L’indicateur d’activité des sessions se fonde sur la séquence de terminal OSC 7501 : un tour interrompu ou une demande d’autorisation sont repérés tout de suite. Il faut Claude Code 2.1.295 ou Codex 0.163 au minimum. Avec une version plus ancienne, la session n’a pas d’indicateur et une notification demande la mise à jour.
- Une issue liée à une session déjà lancée sert de contexte au travail en cours : l’agent continue sans s’y mettre, sauf si vous le lui demandez.

## Corrections

- Après une synchronisation avec Linear, la description d’une issue garde le texte saisi et ses images, sans les recharger.
- Dans l’aperçu en direct de l’éditeur, modifier une ligne de titre, de citation ou de liste ne casse plus le bloc, et les marqueurs saisis restent visibles.
- Les listes de l’éditeur sont correctement indentées, et les lignes longues s’alignent sous le texte de la puce.
