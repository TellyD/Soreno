# Soreno 0.6.4

## What’s new

- **Customize icon and color** is also offered in a project group’s menu: a catalog icon, a color or an imported image, kept when the group is renamed.

## Changes

- On Windows, Ctrl+Backspace deletes the previous word in every session, local, WSL or SSH. On macOS, Option+Backspace does the same.
- On macOS, Soreno is signed and notarized by Apple.
- The **Mobile** button in the status bar is hidden for now.
- On the mobile page, the keyboard opens more smoothly on iOS and Android.
- In a project group’s view, each project’s change count shows below its branch.
- The send button of a line comment keeps its size when the window is narrow.
