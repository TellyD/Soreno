# Soreno 1.2.1

## Nouveautés

- Dans **Design**, la barre de prompt suit chaque envoi : **Envoi…**, **En attente de l’agent…**, **L’agent dessine…** pendant son tour, ou **L’agent attend une réponse** avec **Ouvrir les logs**. Un cadre visé par un prompt est marqué jusqu’à ce que l’agent le réécrive ou termine son tour.
- Pi est proposé comme agent d’un tableau Design.

## Changements

- L’agent d’un tableau Design retouche une copie du cadre actuel au lieu de le réécrire de mémoire : il ne modifie que ce qui est demandé. Le prompt n’embarque plus le HTML du cadre, si bien que la limite de taille n’est atteinte qu’avec un très long texte.
- L’agent d’un tableau Design est lancé avec des droits restreints : ni shell libre, ni capture d’écran, ni serveur. Claude Code et Codex n’écrivent que dans le dossier privé de la session.
