# Soreno 0.7.8

## Changements

- Au tout premier lancement, Soreno s’ouvre sur **Projets** ; ensuite, il rouvre l’espace où vous étiez.
- Dans le formulaire d’un projet, le choix du projet Linear indique l’équipe ou les équipes de chaque projet Linear.
- Le sélecteur de projet du Kanban est plus large.
- Dans **Paramètres** > **Général**, la partie **Terminal** passe après **Notes chiffrées**, juste avant **Diagnostic**.

## Corrections

- Le Kanban affiche le nom actuel d’un projet renommé, dans les issues comme dans les filtres, avec son environnement (local, WSL, SSH).
