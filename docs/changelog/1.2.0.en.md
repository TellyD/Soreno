# Soreno 1.2.0

## What’s new

### Design

The new **Design** view opens a whiteboard where a CLI agent (Claude Code, Codex or OMP) draws screens and components in HTML/CSS. Only the rendering is shown, in frames you can move, resize, duplicate or delete.

- **New board**: name, project (or none) and agent. The agent starts when the board opens, and **Logs** shows its terminal.
- The prompt bar at the bottom talks to the agent about the whole board, the selected frame, or an element of a frame picked in targeting mode (`T`).
- Frames snap to the edges and centers of the others, with alignment guides; Alt turns snapping off. Undo and Redo cover moves, resizes, duplications and deletions.
- Zoom and navigation shortcuts: `Ctrl+=` and `Ctrl+-` to zoom, `Shift+1` to fit everything, `Shift+0` for 100%, `Shift+2` for the selected frame, Space + drag to pan. They are listed in **Settings → Shortcuts**. A board keeps its view from one opening to the next.
- Frames are rendered in isolation, without scripts or external resources. They are stored in Soreno, never in repositories.

### Implementing a design with a coding agent

- **Implement** starts a coding agent on the whole board or on the targeted frame, optionally in a dedicated worktree, with optional **Instructions**. Each frame is attached as an HTML file.
- In the Projects space, a session’s palette icon opens the Design panel in place of the project tools. There you can **Create a design** or link an existing board, which is then sent to the agent. A linked session shows a preview of the board, **Edit in Design**, **Send latest version** and **Unlink**.

## Changes

- In Chat (OMP), `/grill` and `/mockup` are removed: mockups now go through the **Design** view.
- Chat (OMP) follows OMP up to version 18.14.1: a secret input requested by OMP is masked, and a manual compaction is shown while it runs.
- Buttons, menus, dialogs, checkboxes and switches have subtle transitions, turned off when the system asks to reduce motion.
- The mouse back button no longer returns from an issue to the Kanban board.
