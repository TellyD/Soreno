# Soreno 1.0.0

## Nouveautés

### Pull requests et merge requests

Le panneau Git gagne un onglet **Pull requests** (GitHub) ou **Merge requests** (GitLab) pour le dépôt du remote `upstream`, ou à défaut `origin`. Il fonctionne avec github.com et gitlab.com, via les CLI `gh` et `glab` du projet, en local, sous WSL ou en SSH. Soreno ne stocke aucun jeton : si la CLI n’est pas connectée, **Se connecter à GitHub** ou **Se connecter à GitLab** ouvre un terminal pour s’authentifier.

- **Liste** : filtres **Ouvertes**, **Les miennes**, **Revue demandée** et **Fermées / mergées**, et recherche. Chaque ligne affiche les branches, l’état de la CI, la revue et les conflits. La demande de la branche courante passe en tête, marquée **Branche courante**.
- **Détail** : description en Markdown, **Checks**, **Commits** et **Fichiers**. Les diffs sont calculés par Git en local. Panneau agrandi, **Fichiers** passe sur trois colonnes pour la revue.
- **Actions** :
  - **Merger**, avec les seules méthodes autorisées par le dépôt, et **Merger sans vérification** si les checks ont échoué ou sont en cours ;
  - **Marquer comme prête** et **Ouvrir dans le navigateur** ;
  - **Checkout dans un nouveau worktree**, **Checkout dans ce worktree** et **Fermer**, dans le menu **…**.

Le raccourci `Ctrl+Maj+M` (`Cmd+Maj+M` sur macOS) agrandit le panneau Git ou revient au terminal, même quand le terminal a le focus. Si le panneau est fermé, il l’ouvre agrandi.

### Commit automatique des groupes de projets

Dans le panneau Git d’un groupe de projets, **Commit** prépare tous les changements de chaque dépôt, génère avec Codex un message propre à chaque dépôt, puis commite. Un échec est signalé pour son dépôt sans arrêter les autres. Ce bouton remplace le message unique commun aux dépôts et le **Fetch** du groupe.

## Changements

- Supprimer un groupe de projets peut aussi retirer ses projets de Soreno, avec leurs lanceurs et leurs sessions, grâce à une case décochée par défaut. Les dossiers et leurs fichiers restent sur le disque.
- La vue **Automatisations** propose de créer une automatisation dès son état vide.
- Une option tronquée dans une liste déroulante affiche son texte complet au survol.

## Corrections

- Une issue Kanban peut cibler la vue d’ensemble d’un groupe de projets : son agent y démarre, sans worktree, y compris quand l’issue est planifiée.
- Une image insérée dans une note reste séparée du texte par des lignes vides, ce qui permet d’écrire au-dessus et en dessous.
