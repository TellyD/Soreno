# Soreno 0.6.2

## Nouveautés

- Quand **Fusionner dans \<branche principale\> et supprimer** s’arrête sur un conflit, la notification propose **Résoudre avec un agent**. Soreno ouvre dans le worktree une session « Conflits · \<agent\> », avec l’agent qui y travaillait, chargée de résoudre les conflits et de commiter la fusion. Il suffit ensuite de relancer la fusion.
- `Ctrl+F` (`Cmd+F` sur macOS) recherche dans le fichier ouvert dans **Fichiers**, depuis l’éditeur comme depuis l’arborescence : occurrences surlignées, compteur de position, `Entrée` / `Maj+Entrée` pour passer de l’une à l’autre, avec les options **Respecter la casse**, **Mot entier** et **Expression régulière**.
- Les fichiers de **Changements** et ceux d’un commit dans **Historique** ont un menu contextuel (clic droit, touche Menu ou `Maj+F10`) : **Copier le chemin relatif**, **Copier le chemin absolu**, **Insérer le chemin dans l’agent actif** et **Voir l’historique** de ce fichier. Les chemins sont relatifs au projet ; un fichier du dépôt situé hors du projet n’offre aucune action.
- Déplacer une issue du Kanban dans la colonne en cours (In Progress) propose de **Démarrer l’agent** : il démarre dans un worktree du projet de l’issue. **Pas maintenant** déplace l’issue sans agent. Rien n’est proposé si un agent tourne déjà sur l’issue.
- La description d’une issue du Kanban se modifie directement dans son détail, avec l’éditeur des notes (rendu en direct, commandes `/`, images collées) ; elle s’enregistre seule après une pause de frappe ou en quittant le champ.
- **Supprimer le commentaire** supprime un commentaire d’une issue du Kanban, après confirmation.

## Changements

- La barre d’outils de l’arborescence de **Fichiers** affiche le chemin du projet au lieu d’un champ de recherche ; `Ctrl+P` (`Cmd+P` sur macOS) reste le moyen de trouver un fichier. **Actualiser les fichiers** et **Tout replier** sont des boutons directs ; la création d’un fichier ou d’un dossier passe par le clic droit dans l’arborescence, et **Révéler le fichier ouvert** disparaît.
- Les quotas Claude sont lus par Claude Code lui-même (`claude auth status` et `/usage`) au lieu de ses identifiants : Soreno n’accède plus à `~/.claude/.credentials.json` ni au trousseau macOS, et un serveur macOS affiche désormais son compte Claude. Les plafonds par modèle portent le nom affiché par Claude Code ; une session Claude expirée se rétablit avec `/login` dans Claude Code.
- **Insérer le chemin dans l’agent actif** n’affiche plus de notification : l’agent s’affiche déjà avec le chemin saisi.
- Dans la liste des projets, les worktrees n’affichent plus leur chemin, et le worktree de la session active est marqué.
- Dans **Historique**, une branche distante qui suit une branche locale est regroupée dans le badge de celle-ci, au lieu d’un badge séparé.
- Le nom d’un projet s’intitule **Nom affiché** dans son formulaire ; laissé vide, il reprend le nom du dossier.
- Retouches visuelles : fond des champs de saisie, bordures des volets divisés, titre de **Historique** aligné avec son filtre de chemin.

## Corrections

- Une session Claude Code reste **en cours** tant que des agents qu’elle a lancés en arrière-plan (sous-agents, workflows) travaillent, au lieu de passer en attente dès la fin de son propre tour.
- On peut de nouveau ajouter une ligne ou une colonne à un tableau dans l’aperçu d’une note : les boutons **+** apparaissent sous le tableau et à sa droite au survol ou au clavier, et placent le curseur dans la nouvelle cellule.
- **Fusionner dans \<branche principale\> et supprimer**, depuis la liste des projets, fusionne le dernier commit du worktree, y compris un commit fait juste avant, comme celui qui résout un conflit.
