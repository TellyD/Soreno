# Soreno 0.6.3

## Changes

- Soreno no longer keeps forever the small folders it creates each time an agent starts, which hold among other things the agent’s last message, on your computer and on SSH servers: deleting a session also deletes its folders, and those no longer needed to resume disappear after 7 days without activity. The latest launch of each session and sessions still running on a server are always kept.
- **Settings** > **AI** > **Git** has a **Fast mode** switch: on by default as before, it can be turned off to generate commit messages without Codex fast mode, which uses more of your plan.
- In the **Files** tab, `Ctrl+V` (`Cmd+V` on macOS) or **Paste** in the context menu copies into the project the files copied from File Explorer, Finder or your file manager: into the targeted folder, or next to the targeted file. A name already in use gives `name copy.ext`, then `name copy 2.ext`… Folders are not pasted. This also works for WSL and SSH projects, with files up to 32 MiB over SSH.
- A Kanban issue moves to the in-progress column as soon as its agent starts, and back to its original column if the start fails.
- The **Favorites** menu of the session tabs is wider.

## Fixes

- When Git refuses to delete a branch whose commits aren’t merged, Soreno explains why and suggests merging or pushing it first, instead of a generic failure.
- The mobile access service installed on servers now includes the 0.6.1 fix that shows a conversation’s first messages as soon as it opens: the **Mobile** dialog offers **Update** on each enabled server.
