# Soreno 1.3.3

## Nouveautés

- Le panneau Git d’un groupe de projets a un onglet **Branches**. Les branches **Communes** indiquent dans quels dépôts elles sont courantes et basculent tous les dépôts sélectionnés à la fois, en passant ceux qui ne les ont pas. **Créer et basculer** crée une branche dans chaque dépôt sélectionné. Les branches d’un seul dépôt restent rangées sous lui, dans **Par dépôt**.
- Le formulaire d’un projet propose un champ **Groupe** pour l’ajouter directement à un groupe existant de la même machine.

## Changements

- Le choix de l’environnement d’un projet est simplifié : un nouveau projet SSH reprend la dernière connexion SSH enregistrée.
- Le bouton d’ajout d’images est retiré de la création d’issue : les images se collent ou se déposent dans la description.

## Corrections

- Dans les diffs, les surlignages de lignes n’ont plus de jointures, et ceux des fragments renvoyés à la ligne ne se superposent plus.
- L’indicateur des contrôles segmentés ne glisse plus qu’au changement de sélection, et non à l’affichage.
