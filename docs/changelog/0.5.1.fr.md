# Soreno 0.5.1

## Corrections

- L’accès mobile s’active désormais sur les serveurs sans systemd, comme les conteneurs Gitpod et les devcontainers, où l’activation échouait. Le service y tourne en arrière-plan, et chaque lancement d’une session SSH par Soreno le relance s’il s’est arrêté ; le dialogue **Mobile** affiche **Mise à jour nécessaire** tant qu’il est arrêté.
- Sur un serveur avec systemd, l’activation n’échoue plus quand le maintien du service après déconnexion est déjà actif. S’il ne l’est pas et que le serveur refuse de l’activer pour votre compte, il suffit qu’un administrateur lance une fois `sudo loginctl enable-linger <compte>`.
