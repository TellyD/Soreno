# Soreno 0.7.6

## Nouveautés

- **Phrase de passe oubliée :** **Paramètres** > **Général** > **Notes chiffrées** propose **Oubliée ? Réinitialiser**. Après confirmation, toutes les notes chiffrées et leurs images sont définitivement supprimées, dans tous les coffres, et chiffrer une note définira une nouvelle phrase de passe. Les autres notes sont conservées.

## Changements

- Le titre d’une note chiffrée reste lisible, dans la liste comme sur le disque : seul son contenu est chiffré. Une note chiffrée avec la 0.7.5 reste affichée comme **Note chiffrée** jusqu’à sa prochaine modification.
- Le panneau Git n’affiche plus qu’une action de synchronisation, celle qui sert : **Push**, **Pull**, **Publier** pour une branche sans branche distante, ou l’état (**À jour**, **Aucun remote**…). Les autres actions passent dans le menu **Autres actions**, et le nombre de commits s’affiche en pastille.
- Sur une branche qui a divergé, **Pull** échoue avec un message clair qui renvoie vers **Pull avec rebase**. **Push** est bloqué tant que la branche distante a des commits absents en local.
- Un seul indicateur de progression s’affiche, sur l’action Git en cours, y compris pendant un **Commit automatique**.
- L’aperçu d’une maquette ne clignote plus en blanc à l’ouverture ; en largeur **Bureau**, il occupe tout le panneau, avec des barres de défilement aux couleurs du thème.
