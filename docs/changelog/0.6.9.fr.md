# Soreno 0.6.9

## Nouveautés

### Style des messages de commit

**Paramètres** > **IA** > **Messages de commit** propose un **Style par défaut** pour les messages générés par Codex : **Impératif** (une ligne courte, verbe à l’impératif), **Conventional Commits** (type et portée facultative en préfixe) ou **Sujet + corps** (sujet court, puis un bref paragraphe qui explique pourquoi), avec un aperçu. Les conventions de commit de l’`AGENTS.md` du dépôt restent prioritaires.

### Objectifs dans le Chat (OMP)

`/goal <objectif>` fixe un objectif à la session : OMP poursuit son travail tour après tour jusqu’à l’atteindre, comme dans son terminal. `/goal` seul l’affiche, et `/goal pause`, `resume` ou `drop` le mettent en pause, le reprennent ou l’abandonnent. Son état (actif, en pause, budget atteint) s’affiche sous la zone de saisie.

### Identité Git pour tous les dépôts

Le dialogue qui demande le nom et l’e-mail de l’auteur avant un commit propose **Utiliser pour tous les dépôts**, pour enregistrer cette identité dans la configuration Git globale plutôt que dans le seul dépôt.

## Changements

- Dans le Chat (OMP), `/` ne propose plus que les commandes d’OMP utiles dans le chat ; celles qui doublent les contrôles de Soreno ou exigent son terminal sont masquées.
- Les skills utilisés par un agent sont mis en évidence dans la conversation, sous un nom simplifié.
- **Masquer les outils et le raisonnement** se trouve désormais à côté de l’indicateur de contexte, sous la zone de saisie.
- Retouches visuelles : ligne d’activité de l’agent qui ne bouge plus pendant les outils, coins des choix segmentés, anneau de focus réservé à la navigation au clavier.

## Corrections

- Le Chat (OMP) reste collé au bas de la conversation quand une image se charge en retard.
- Sur un serveur SSH dont les commandes système sont celles de uutils (Ubuntu 26.04 par exemple), des lectures simultanées ne se mélangent plus et l’enregistrement d’un fichier ne risque plus d’entrer en conflit avec un autre.
