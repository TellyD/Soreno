# Soreno 1.4.7

## Nouveautés

- Dans les **Options d’affichage** du rail, regroupées par statut, les sessions se trient par **Projet** ou par **Plus récentes**, et le choix est mémorisé.
- L’option **Terminaux** de **Afficher** masque les sessions de terminal et de service pour ne garder que les agents.

## Changements

- Regroupées par statut, les sessions en cours placent en tête celles dont l’agent travaille.
