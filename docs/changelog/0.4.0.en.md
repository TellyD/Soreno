# Soreno 0.4.0

## What’s new

### Agent settings

New **Agents** page in the settings: uncheck an agent to remove it from the new-session menu and from the agent picker on a Linear issue. Terminal is always available. The page shows the command run for each agent; Soreno doesn’t install them, each one must already be present in the project’s environment (local, WSL or SSH server).

### AI settings and Git model

The **Assistant** settings tab becomes **AI** and is split into three cards: Codex (installation and updates), **Note assistant** (model and effort of the assistant panel) and **Git**. The **Git** card chooses the model used to generate commit messages and to review a commit from the history; effort stays low for quick answers.

### Linear: summaries signed by the agent

The summary an agent posts on an issue is signed with the agent’s name. In the issue detail, that comment shows the agent’s icon and name instead of yours, since Linear credits it to the owner of the API key.

## Changes

- The Git panel’s **Review** tab is gone. Reviewing a commit is still available from the history.
- The **Terminal log** is off by default: turn it on in **Settings** > **General** when you need it, without restarting sessions. When off, nothing is recorded.
- The branch shown in the project list updates as soon as the Git panel reads the repository or an agent finishes its turn, without waiting for the next refresh.
- The button that shows or hides the note list now uses the same icon and selected state as the project panel button.
