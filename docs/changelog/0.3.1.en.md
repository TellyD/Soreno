# Soreno 0.3.1

## Changes

- The **Kanban** entry now sits above the project list header, instead of being the first row of the list.
- When the Git panel cannot read a repository, the message now gives the cause and what to do: another Git operation is already running, Git did not respond in time, the repository folder cannot be reached, or Git returned an unexpected or oversized response.

## Fixes

- Moving the cursor in a long note is smoother in live preview: only the affected blocks are redrawn.
- The project list stays more responsive with many projects and sessions.
