# Soreno 0.1.14

## What’s new

### Group agents

Each project group now has an **Overview** row. Its **+** button launches an agent that works across all the projects in the group, instead of a single repository.

- The overview’s working folder is created on first click, in `~/.soreno/groups` on the projects’ machine. For an SSH group, reconnect the server first.
- Claude Code and OMP receive the list of repositories and access to their folders. Pi receives only the list, and Codex only folder access.
- On Windows, a group that is too large (about 12 to 18 repositories, depending on path length) cannot launch a group agent: Soreno tells you.
- Deleting a group deletes its overview sessions and their conversations. The group’s projects are kept.

### Image previews

The **Files** tab now displays project images (PNG, JPEG, GIF, WebP, AVIF, BMP) up to 1 MB, instead of opening them as text.

## Changes

- Projects in a group must now be on the same machine: local, the same WSL distribution, or the same SSH server. In the group form, projects on another machine cannot be selected. To change the machine of a grouped project, remove it from its group first.
- Your existing groups are carried over automatically. If a group mixed several machines, projects that are not on the same machine as most of the group leave it, and a notification lists them.
- The Git identity dialog is now titled **Set commit author identity**. It explains that this name and email are written to commits and are separate from your GitHub account, and how to keep your email private with GitHub’s noreply address.
- The project list shows up faster at launch, with a more visible loading indicator.

## Fixes

- The project list no longer stays stuck on the loading indicator when a project’s worktrees cannot be read: it shows up and retries right away.
- A terminal receiving a lot of continuous output is no longer redrawn over and over.
