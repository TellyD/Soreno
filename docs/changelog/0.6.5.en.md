# Soreno 0.6.5

## What’s new

### Linear issues in the Kanban

- The Kanban can show the issues of a Linear team next to the local issues: **Connect Linear** in the board header, with a Linear API key. Both sources share the same columns; a Linear issue shows its identifier and a **Linear** badge, and an **All / Local / Linear** filter narrows the board. Without a connection, the Kanban stays purely local.
- Changes made in Soreno (state by drag and drop, title, priority, labels, description, comments, deletion) are made directly in Linear. Your teammates’ changes show up when you come back to the window, every 5 minutes while the Kanban is on screen, or right away with **Refresh**. If Linear can’t be reached or rejects the key, local issues stay on the board.
- A new issue goes by default to the filter’s source (with **All**, the last destination you chose); the destination can still be changed when creating, and a sub-issue stays in its parent’s source.
- An agent started on a Linear issue posts its summary as a Linear comment and moves the issue to review; an issue it creates goes to the same Linear team.
- A Soreno project can be linked to a Linear project: its Linear issues show up under that project in the filter, and an agent started from one of them starts in that project.
- **Send to Linear**, in a local issue’s details, moves it to the Linear team on screen, with its comments carried over at the end of the description; the linked agent session follows it.

### Switch sessions from the keyboard

**Ctrl+Tab** shows the project’s next session tab and **Ctrl+Shift+Tab** the previous one, on macOS and Windows alike. A stopped session is only selected, not restarted.

### Colored file icons

**Settings › General › Colored file icons** shows a colored icon per file type, from Material Icon Theme, in the explorer, Git changes, quick open and search. Git changes then show the status letter next to each file. Off by default.

### Editing shortcuts in agent terminals

- On macOS, the Terminal, iTerm2 and VS Code shortcuts work in sessions: ⌘← / ⌘→ go to the start or end of the line, ⌘⌫ deletes to the start and ⌘⌦ to the end, ⌥← / ⌥→ move word by word, ⌥⌦ deletes the next word.
- On Windows, Ctrl+Delete deletes the next word.
- ⌘A (macOS) or Ctrl+Shift+A selects the whole terminal.

## Changes

- **Settings › Skills** hides projects without skills by default, with the **Hide projects without skills** option.
- Visual touch-ups: accent colors on settings controls and skill icons, larger switches, animated segmented control selection, Git tree folders colored with file icons, project card background hidden while one of its sessions is active.
