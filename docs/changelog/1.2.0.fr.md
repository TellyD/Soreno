# Soreno 1.2.0

## Nouveautés

### Design

La nouvelle vue **Design** ouvre un tableau blanc où un agent CLI (Claude Code, Codex ou OMP) dessine des écrans et des composants en HTML/CSS. On ne voit que le rendu, dans des cadres que l’on déplace, redimensionne, duplique ou supprime.

- **Nouveau tableau** : nom, projet (ou aucun) et agent. L’agent démarre à l’ouverture du tableau, et **Logs** affiche son terminal.
- La barre de prompt, en bas, s’adresse à l’agent pour tout le tableau, pour le cadre sélectionné ou pour un élément d’un cadre choisi en mode ciblage (`T`).
- Les cadres s’aimantent aux bords et au centre des autres, avec des repères d’alignement ; Alt désactive l’aimantation. Annuler et Rétablir reprennent les déplacements, redimensionnements, duplications et suppressions.
- Raccourcis de zoom et de navigation : `Ctrl+=` et `Ctrl+-` pour zoomer, `Maj+1` pour tout afficher, `Maj+0` pour 100 %, `Maj+2` pour le cadre sélectionné, Espace + glisser pour déplacer la vue. Ils sont listés dans **Paramètres → Raccourcis**. Le tableau conserve sa vue d’une ouverture à l’autre.
- Les cadres sont rendus isolés, sans script ni ressource externe. Ils sont stockés dans Soreno, jamais dans les dépôts.

### Implémenter un design avec un agent de code

- **Implémenter** lance un agent de code sur tout le tableau ou sur le cadre ciblé, éventuellement dans un worktree dédié, avec des **Instructions** facultatives. Chaque cadre lui est joint en fichier HTML.
- Dans l’espace Projets, l’icône palette d’une session ouvre le panneau Design à la place des outils du projet. On peut y **Créer un design** ou lier un tableau existant, qui est alors transmis à l’agent. Une session liée affiche un aperçu du tableau, **Modifier dans Design**, **Transmettre la dernière version** et **Délier**.

## Changements

- Dans le Chat (OMP), `/grill` et `/mockup` sont retirés : les maquettes passent par la vue **Design**.
- Le Chat (OMP) suit OMP jusqu’à la version 18.14.1 : une saisie secrète demandée par OMP est masquée, et une compaction manuelle est signalée pendant qu’elle s’exécute.
- Les boutons, menus, dialogues, cases à cocher et interrupteurs ont des transitions discrètes, désactivées quand le système demande de réduire les animations.
- Le bouton précédent de la souris ne ramène plus d’une issue au tableau du Kanban.
