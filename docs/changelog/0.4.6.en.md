# Soreno 0.4.6

## What’s new

### Search in project

Ctrl+Shift+F (Cmd+Shift+F on macOS) opens **Search in project**: it searches the content of the selected project’s files, with **Match case**, **Match whole word** and **Use regular expression** options (Alt+C, Alt+W, Alt+R from the field). Selected text on a single line pre-fills the search; otherwise the last search is reused. Results are grouped by file, exclude files ignored by Git and are limited to the first 1,000. Choosing a result opens the file in **Files** at the matching line, with the match selected. Search works locally, on WSL and over SSH.

## Changes

- The built-in chat is removed, along with its sessions and conversations.
- The Git panel refreshes faster in large repositories and over SSH: between reads, Soreno only reads again the files that changed. The **Terminal log** also records how long these reads take.
- **Settings** > **General** now groups its options into two parts, **Interface** and **Terminal**.
- Summaries posted by an agent on a Linear issue are written in Markdown: one sentence, then a list of the changes and checks run.

## Fixes

- In Linear issues, inline code is readable in both light and dark themes, and links written by Linear between angle brackets (`[text](<address>)`) display correctly.
