# Soreno 0.6.8

## What’s new

### Chat (OMP) survives closing Soreno over SSH

On a Linux SSH server, a **Chat (OMP)** session keeps running when you close Soreno or lose the connection, like terminals: OMP carries on with its turn, and reopening the session finds it again, with OMP’s questions still waiting for your answer. **Stop** ends it on the server. On a macOS server, the Chat still stops with Soreno.

### Auto commit

In the Git panel, **Auto commit** (the ✦ icon left of **Commit**) does it all in one click: it stages every change, untracked files included, generates the message with Codex and creates the commit, without review. If Codex isn’t installed, nothing is changed and the notification points to **Settings** > **AI**; if generation fails, files stay staged and no commit is created. The button is disabled during a merge, with conflicts or on a detached HEAD.

### Chat (OMP)

- **↑** on the composer’s first line recalls the messages sent in the conversation, and **↓** moves back to the latest ones, then restores the current draft.
- Like terminal agents, Chat (OMP) can create a Kanban issue when you ask it to.

## Changes

- In Chat (OMP), running subagents only show above the composer; once finished, they stay under the call that started them.
- **Settings** > **Skills** groups skills into **Updatable** and **Not updatable**.
- **Settings** > **General** gains icons and a **Theme** section.
- Chat (OMP) conversation text and icons are pixel-aligned.

## Fixes

- In Chat (OMP), **Stop** no longer does nothing when only OMP background jobs are still running: the view says so and the button stops them.
- With the interface in English, a Git error about an unexpected response no longer shows details in French.
