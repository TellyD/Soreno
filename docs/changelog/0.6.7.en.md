# Soreno 0.6.7

## What’s new

### A more complete Chat (OMP)

- **Mentions and commands**: `@` suggests the project’s files, recent ones first; `/` suggests OMP commands and skills. Arrows, **Enter** or **Tab** insert the suggestion, **Escape** closes the list.
- **Attachments**: paste, drop or pick with the paperclip any file. Images go with the message if the model reads them, text files are copied into the message, and any other file is transferred to the conversation’s private folder, as in a terminal.
- **Queued messages**: a message sent during a step waits its turn and can be canceled; stopping the step puts queued messages back in the composer.
- **Hide tools and reasoning**, in the **…** menu, keeps only the replies; the choice applies to every conversation and is remembered.
- **Update OMP** appears when a newer OMP version is available in the project’s environment.
- Running subagents show above the composer, with their type.
- A conversation gets a title as in OMP’s terminal, reused as the session name.
- In an OMP question, the suggested answer is marked **Recommended**, and the session shows as waiting for a reply while the question is open.
- **Resolve with an agent**, after a worktree merge conflict, opens a new **Chat (OMP)** conversation when that is the worktree’s agent.

## Changes

- The chat stays in its starting state until OMP answers, instead of looking ready too early.
- Long OMP notices are collapsed in the conversation.
- A todo list with a single phase no longer shows the “Tasks” heading.

## Fixes

- In conversations, the Kanban and release notes, Markdown list items separated by a blank line stay in the same list.
