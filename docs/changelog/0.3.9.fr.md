# Soreno 0.3.9

## Changements

- Le Kanban Linear retient le filtre de projet choisi pour chaque équipe, y compris après un redémarrage de Soreno.
- L’icône affichée quand vous déposez un fichier sur le terminal prend la couleur du texte.

## Corrections

- Le terminal ne ralentit plus Soreno ni le reste de l’ordinateur quand un agent affiche une interface pleine de cadres et de séparateurs (Claude Code, OMP) : l’écran est beaucoup moins coûteux à dessiner.
