# Soreno 0.3.8

## What’s new

### A smooth terminal, even during large redraws

The agent terminal has been rebuilt: the screen is now computed in the background, outside the interface. When Pi or OMP redraw a whole long conversation, Soreno no longer stutters or freezes, even after hours of use. Hidden tabs stay up to date and show up instantly when you come back to them.

### Linear: send a comment to the agent

Each comment of an issue offers **Send to the agent**. The agent receives the issue identifier, title and link, the author and the comment at the end of its current turn. The session linked to the issue comes first, then the running agents of the Soreno project linked to the issue’s Linear project; when there are several, **Choose the agent** opens a menu. The comment then shows **Sent**, **Delivered** or **Not delivered** with the reason, even after the session stops.

## Changes

- When the agent uses the mouse, right-click goes to the agent; Shift + right-click opens the terminal menu.
- New **Terminal log** setting (Settings → General): copies the path of a performance log to attach when reporting a display problem.
- Soreno checks for updates every hour, and when you come back to the window if the last check is more than an hour old: a new version shows up without relaunching the app, and an even newer one replaces the offered version until its download starts.

## Fixes

- Claude Code reads the comments Soreno sends (diff, Linear) without asking for permission on every message, including over SSH.
- The Git panel no longer shows an error when an agent deletes or replaces a file while it is being read: Soreno reads the repository again automatically.
