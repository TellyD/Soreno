# Soreno 1.4.3

## What’s new

- In messages, a wide table scrolls horizontally instead of widening the message, and **Expand table**, shown on hover or keyboard focus, opens it large in a dialog.
- A Linear issue’s details show who created it (**Created by**).
- In **Link an issue**, issues are grouped by project, the session’s first, then sorted from the most advanced state to the least, and from the most recently updated to the oldest.

## Fixes

- In an issue, the description toolbar no longer covers the text while scrolling.
- In the editor, checkboxes are vertically aligned with the text.
