# Soreno 0.7.6

## What’s new

- **Forgotten passphrase:** **Settings** > **General** > **Encrypted notes** offers **Forgot it? Reset**. After confirmation, every encrypted note and its images are permanently deleted, in every vault, and encrypting a note will set a new passphrase. Other notes are kept.

## Changes

- An encrypted note’s title stays readable, in the list and on disk: only its content is encrypted. A note encrypted with 0.7.5 still shows as **Encrypted note** until its next edit.
- The Git panel now shows a single sync action, the useful one: **Push**, **Pull**, **Publish** for a branch without a remote branch, or the status (**Up to date**, **No remote**…). Other actions move to the **More actions** menu, and the commit count shows as a badge.
- On a diverged branch, **Pull** fails with a clear message pointing to **Pull with rebase**. **Push** is blocked while the remote branch has commits you don’t have.
- A single progress indicator shows, on the running Git action, including during an **Auto commit**.
- A mockup preview no longer flashes white when it opens; at **Desktop** width, it fills the whole panel, with theme-colored scrollbars.
