# Soreno 0.1.11

## Nouveautés

### Glisser-déposer des fichiers dans un terminal

Déposez des fichiers sur le terminal d’une session en cours pour les transmettre à l’agent : leurs chemins sont insérés dans la saisie, prêts à être envoyés.

- Jusqu’à 16 fichiers à la fois, 32 Mio maximum par fichier.
- Les fichiers ne sont pas ajoutés à votre projet : Soreno en fait une copie dans un dossier temporaire privé, supprimé quand la session s’arrête.
- Cela fonctionne aussi pour les projets WSL et SSH : sur un serveur SSH, les fichiers sont envoyés automatiquement.

## Changements

- L’espace **Agents** s’appelle maintenant **Projets**.
- Dans le panneau Git, le bouton **Ouvrir un dépôt** devient **Ajouter un projet**.
- Sur les serveurs SSH, Soreno range désormais ses fichiers dans `~/.cache/soreno` au lieu de `~/.cache/telaoi`. Les sessions SSH encore ouvertes avec une version précédente ne sont pas retrouvées après la mise à jour : arrêtez-les avant de mettre à jour. Vous pouvez ensuite supprimer l’ancien dossier `~/.cache/telaoi` sur le serveur.
