# Soreno 0.4.10

## Changements

- Les quotas Codex et Claude ne se rafraîchissent plus quand la fenêtre de Soreno est masquée ou réduite ; un retour sur la fenêtre rattrape le rafraîchissement manqué.
- Codex lancé par Soreno respecte de nouveau le mode de sandbox et la politique d’approbation de votre `config.toml`, y compris depuis une issue Linear ou dans un groupe de projets. Les dossiers que Soreno lui ouvre en écriture ne servent qu’en mode `workspace-write` ; en lecture seule, Codex demande avant d’écrire.
- Sur la page mobile, une session Pi ou OMP dont l’historique a été supprimé alors que l’agent tourne encore affiche **Conversation supprimée**, sans champ de message.

## Corrections

- Sous Windows, la lecture des quotas Codex ne risque plus de forcer le redémarrage de l’ordinateur : Soreno laisse `codex app-server` se fermer seul au lieu de l’arrêter de force.
