# Soreno 0.4.5

## What’s new

### Chat: add context with @

In the chat, type `@` to mention a project file or folder: Soreno suggests matching paths, attaches their content to the message and lets you preview it before sending.

### Sort changed files

In Changes, the **Sort files** menu orders each group **By path** (default), **Most changed first** or **Least changed first**, by the number of added and removed lines. Binary and untracked files stay at the end of the group, and the previous/next arrows follow this order. The choice is remembered and also applies to project group diffs.

## Changes

- The chat is marked as experimental and is no longer offered by default: turn it on in **Settings** > **Agents**. If you have changed your settings since 0.4.0, your agent choice stays as it is.
- The default **worker** chat agent now uses the GPT-6.1 Sol model.

## Fixes

- A disconnected SSH project, or one not connected when Soreno starts, keeps its worktree grouping in the project list.
- The chat no longer loses a message sent just as a step starts, no longer cuts off a reply in progress when an error is shown, and marks messages waiting on a restarted session as not sent.
- In an SSH project, chat commands run in the project folder even if the server’s login profile changes directory.
- Shift+Tab leaves the chat’s `/` command suggestions.
