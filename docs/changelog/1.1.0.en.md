# Soreno 1.1.0

## What’s new

### More reliable messages to agents

- Soreno’s messages to an agent, such as a forwarded comment, an issue being linked or a diff comment, wait until text typed in its terminal is submitted with Enter or dropped with `Ctrl+C`. Otherwise they would be appended to it. The message’s status then says why it is waiting.
- Claude Code and Codex no longer receive anything during their startup screens (folder trust, hook review), where Enter could pick an option, often quitting.
- An issue can be linked to or unlinked from a stopped session. The message waits for the session’s next start, even after Soreno is closed.
- When an agent replaces a local issue’s description, the previous description is first added as a comment.
- In a group overview, Codex also receives the list of the group’s repositories.

### Search across a whole group

From a project group’s overview, `Ctrl+P` and `Ctrl+Shift+F` (`Cmd` on macOS) search every connected project in the group, with results prefixed by the project name. A project in error does not hide the others. Picking a result selects the project and opens the file in **Files**.

## Changes

- Info notifications dismiss themselves, even when they offer an action such as **Open**.

## Fixes

- The Kanban names agent sessions like their tabs: custom name, otherwise the conversation name, otherwise the terminal title.
