# Soreno 0.3.5

## What’s new

### Terminal theme

In **Settings** > **General**, **Terminal theme** sets the appearance of agent and service terminals independently of the interface: **Match interface**, **Light** or **Dark**. The light theme has its own color palette, readable on a light background.

### Rename a session

Right-click a session tab, then **Rename session**. The name you choose replaces the one the agent sets automatically, including on Linear cards. Leave it empty to use the automatic name again.

## Changes

- In **Settings** > **Assistant**, the provider is chosen only with the **Provider** selector: the second panel offering to enable the other provider is gone.
- The project group dialog shows each project’s icon and environment (local, WSL, SSH) next to its path.
- Moving a project to a group on another machine now explains why it can’t be done, naming the project, the group and their machines.
- Form and confirmation dialogs are slightly wider.

## Fixes

- An external worktree opened from the project list appears under its repository right away, instead of standing apart until the next refresh.
- The project picker for starting an agent on a Linear issue no longer offers worktrees whose folder was deleted outside Soreno.
