# Soreno 0.4.8

## What’s new

### Mobile access to SSH sessions

Follow and steer the agents of your SSH servers (Pi, OMP, Claude Code, Codex) from your phone, even with this computer off. The **Mobile** dialog in the status bar, next to **Ports**, checks the requirements (compatible Linux server, Tailscale connected on the server, HTTPS publishing) and gives the command to run for each, then **Enable mobile access** installs the service on the server and shows the address to open on the phone, with a QR code. Several servers can be enabled: a main server gathers the sessions of all the others on the same page. On the phone, the page lists sessions, shows each conversation with its tools and lets you send the agent a message, without changing the terminal size on the computer.

In an SSH session tab, **Copy attach command** also gives the command that joins this session from another terminal or a mobile SSH client.

### Manage skills

New **Skills** page in the settings: it lists the skills installed for your agents, globally and in each project, on this computer, on WSL and on your SSH servers. Filter the list, remove a skill, and update the ones installed from skills.sh when their repository changed (**Update available**, **Update all**). A disconnected project or server is flagged without opening an SSH connection.

## Changes

- **Insert path in active agent** replaces picking an agent in the **Files** tab menu: the path goes to the agent of the active pane.
- The usage indicator in the status bar shows weekly usage instead of the busiest window.
- The **Terminal log** also records the detailed cause of failed Git reads.

## Fixes

- After sleep or a network change, an SSH project’s Git panel no longer shows “repository folder can’t be reached”: the read is retried once on a fresh connection.
- When the file shown in Changes is no longer modified, the Git panel updates instead of showing an error.
- The terminal cursor stays solid while typing and only blinks when idle.
- Codex launched by Soreno no longer warns that its shared server is missing.
