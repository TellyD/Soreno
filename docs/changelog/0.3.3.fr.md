# Soreno 0.3.3

## Changements

- Les opérations Git ne demandent plus d’arrêter les sessions d’agent ouvertes : retirer de la préparation, committer, restaurer, changer de branche, initialiser un dossier, fetch, pull, push et clone fonctionnent sans les interrompre. Un agent qui écrit pendant l’opération peut laisser des fichiers modifiés juste après ; relisez le panneau Git si besoin.
- Plus besoin d’arrêter l’agent avant **Marquer résolu** sur un conflit.
- **Fusionner dans \<branche principale\> et supprimer** n’arrête que les sessions du worktree supprimé, comme avant. Les sessions des autres worktrees, projets ou machines ne bloquent plus la fusion.
- Les erreurs « Des sessions tournent dans ce dépôt » et « Soreno n’a pas pu identifier avec certitude le dépôt utilisé par une session active » disparaissent, y compris entre environnements local et WSL.
