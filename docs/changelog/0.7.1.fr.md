# Soreno 0.7.1

## Changements

- L’accès mobile change d’adresse : la page s’ouvre désormais sur `https://mobile.soreno.dev` et les serveurs joignent le relais par son nom, `relay.soreno.dev`. Sur chaque serveur déjà activé, le dialogue **Mobile** propose **Mettre à jour** ; les téléphones doivent ensuite être appairés une fois (**Appairer un téléphone**). Les échanges restent chiffrés de bout en bout.
- Pendant un cadrage (`/grill`), **Revenir sur** une décision fait reposer la question par OMP : la nouvelle réponse remplace l’ancienne dans la colonne **Cadrage**, et **Synthétiser** est de nouveau proposé après une décision prise depuis la dernière synthèse. Une question ignorée est listée **Sans réponse** sans compter comme décision. La synthèse s’affiche dans la conversation, avec son bouton **Copier**.
- Pendant un cadrage, OMP tranche seul les choix évidents en l’annonçant, au lieu de poser une question pour chacun.

## Corrections

- Dans les conversations, les listes numérotées gardent leur numéro de départ et leur indentation.
- Le formulaire d’un groupe de projets ne propose plus les projets dont le dossier est introuvable, sauf s’ils font déjà partie du groupe.
- L’onglet Git sélectionné garde les couleurs du thème.
