# Soreno 0.4.7

## What’s new

### File actions

In the Git panel’s **Files** tab, right-clicking a file or folder (or pressing the Menu key, or Shift+F10) opens its actions:

- **Copy relative path** or **Copy absolute path**, and **Insert path in** a running agent of the project, which is then shown with the path typed into its terminal.
- **Show changes** for a modified file, and **Show history** limited to that file or folder.
- **New file…**, **New folder…**, **Rename or move…** (missing folders are created), **Duplicate** and **Delete…**. Deletion is always confirmed and permanent, without going to the trash; a name already in use is refused.

The **More file actions** menu in the tree’s toolbar can also **Reveal open file** and **Collapse all**. Each modified file shows its Git status, and folders containing changes show a dot. These actions work locally and over SSH.

## Changes

- **Open** in the notification for an issue created by an agent now shows the issue in Soreno’s Kanban instead of opening it in the browser.
- In a Linear issue’s detail, the form to start a new agent is separated from the last session by a line.
- A project group’s overview no longer shows the changes summary when there are none.

## Fixes

- Quick file search no longer returns stale results after a folder stops being a Git repository.
