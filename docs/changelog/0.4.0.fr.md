# Soreno 0.4.0

## Nouveautés

### Paramètres des agents

Nouvelle page **Agents** dans les paramètres : décochez un agent pour le retirer du menu de création de session et du choix de l’agent sur une issue Linear. Le terminal reste toujours disponible. La page rappelle la commande lancée pour chaque agent ; Soreno ne les installe pas, chacun doit déjà être présent dans l’environnement du projet (local, WSL ou serveur SSH).

### Paramètres IA et modèle de Git

L’onglet **Assistant** des paramètres devient **IA** et se divise en trois cartes : Codex (installation et mises à jour), **Assistant de notes** (modèle et effort du panneau assistant) et **Git**. La carte **Git** choisit le modèle utilisé pour générer les messages de commit et pour la revue d’un commit dans l’historique ; l’effort reste faible pour des réponses rapides.

### Linear : résumés signés par l’agent

Le résumé qu’un agent publie sur une issue est signé du nom de l’agent. Dans le détail de l’issue, ce commentaire s’affiche avec l’icône et le nom de l’agent au lieu de votre nom, puisque Linear l’attribue au propriétaire de la clé d’API.

## Changements

- L’onglet **Revue** du panneau Git disparaît. La revue d’un commit reste disponible depuis l’historique.
- Le **Journal du terminal** est désactivé par défaut : activez-le dans **Paramètres** > **Général** quand vous en avez besoin, sans relancer les sessions. Désactivé, rien n’est enregistré.
- La branche affichée dans la liste des projets se met à jour dès que le panneau Git relit le dépôt ou qu’un agent termine son tour, sans attendre la prochaine actualisation.
- Le bouton qui affiche ou masque la liste des notes reprend l’icône et l’état sélectionné du bouton du panneau de projet.
