# Soreno 0.4.6

## Nouveautés

### Rechercher dans le projet

Ctrl+Maj+F (Cmd+Maj+F sur macOS) ouvre **Rechercher dans le projet** : la recherche porte sur le contenu des fichiers du projet sélectionné, avec les options **Respecter la casse**, **Mot entier** et **Expression régulière** (Alt+C, Alt+W, Alt+R depuis le champ). Le texte sélectionné, s’il tient sur une ligne, pré-remplit la recherche ; sinon la dernière recherche est reprise. Les résultats sont groupés par fichier, sans les fichiers ignorés par Git, dans la limite des 1 000 premiers. Choisir un résultat ouvre le fichier dans **Fichiers** à la ligne trouvée, l’occurrence sélectionnée. La recherche fonctionne en local, sous WSL et en SSH.

## Changements

- Le chat intégré est retiré, avec ses sessions et ses conversations.
- Le panneau Git s’actualise plus vite dans les gros dépôts et en SSH : d’une lecture à l’autre, Soreno ne relit que les fichiers qui ont changé. Le **Journal du terminal** enregistre aussi la durée de ces lectures.
- **Réglages** > **Général** regroupe ses options en deux parties, **Interface** et **Terminal**.
- Les résumés publiés par un agent sur une issue Linear sont rédigés en Markdown : une phrase, puis la liste des changements et des vérifications.

## Corrections

- Dans les issues Linear, le code en ligne est lisible en thème clair comme en sombre, et les liens écrits par Linear entre chevrons (`[texte](<adresse>)`) s’affichent correctement.
