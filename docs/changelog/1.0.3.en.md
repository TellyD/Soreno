# Soreno 1.0.3

## What’s new

### Kanban issues in the side panel

In the Kanban, an issue opens in the right panel, next to the board, instead of replacing the board. The Git panel shortcuts apply: `Ctrl+Alt+B` (`Cmd+Option+B` on macOS) hides or shows the issue, and `Ctrl+Shift+M` (`Cmd+Shift+M` on macOS) expands it or returns to the board. A Linear issue from another team is shown with that team.

### Slash commands and images in the editor

- The `/` command menu is organized in sections, with an icon for each command, in the toolbar’s order.
- An image alone on its line stays rendered when the cursor is on it. Arrow keys skip over its source, and typing or pasting beside it opens a new paragraph.

## Changes

- The session activity indicator relies on the OSC 7501 terminal sequence, so an interrupted turn or a permission request is detected right away. It requires Claude Code 2.1.295 or Codex 0.163 at least. With an older version, the session has no indicator and a notification asks you to update.
- An issue linked to a session that is already running serves as context for the work under way: the agent carries on without starting on it, unless you ask.

## Fixes

- After a sync with Linear, an issue’s description keeps the typed text and its images, without reloading them.
- In the editor’s live preview, editing a heading, quote or list line no longer breaks the block, and typed markers stay visible.
- Editor lists are indented correctly, and long lines align under the bullet’s text.
