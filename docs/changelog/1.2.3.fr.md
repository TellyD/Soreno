# Soreno 1.2.3

## Nouveautés

- Dans le rail des projets, une session se ferme depuis sa ligne, avec le bouton **Fermer l’onglet** qui apparaît au survol ou au focus clavier, sans quitter le projet courant. Les sessions épinglées n’ont pas ce bouton.
- Dans l’éditeur, un double-clic sur une image l’ouvre en aperçu, de même qu’Entrée sur une image sélectionnée.

## Corrections

- Changer de vue garde la barre latérale masquée par `Ctrl+B`. Cliquer à nouveau sur la vue active la réaffiche.
- Dans le panneau Git, la barre de défilement ne masque plus les actions des fichiers, notamment sur macOS.
