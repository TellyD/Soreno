# Soreno 1.0.1

## What’s new

- `Ctrl+,` (`Cmd+,` on macOS) opens the settings, even when the terminal has focus. On macOS, the application menu also offers **Settings…**.

## Changes

- In the settings, encrypted notes have their own **Notes** section.
- In the settings, the OMP command list and the skill lists are collapsed by default; **Show commands** expands the command list.
- Session tabs scroll horizontally with the mouse wheel.

## Fixes

- In a diff, highlighting of changed characters now compares lines that match each other, instead of comparing them in order.
- A Git operation that stops a project’s sessions no longer prevents starting the sessions of other projects.
- A project or worktree with a session that still has an automation, even a paused one, can no longer be deleted: a message explains that it must first be deleted from the **Automations** view.
