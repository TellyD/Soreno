# Soreno 0.8.0

## Nouveautés

### Services des groupes de projets

Dans un groupe de projets, le bouton **Services** et son panneau rassemblent les services de tous les projets SSH du groupe, classés par projet, chacun avec son **Tout démarrer**. Ils sont accessibles depuis n’importe quel projet du groupe, un de ses worktrees ou la vue d’ensemble, et le panneau reste ouvert ou fermé pour tout le groupe.

## Changements

- La ligne d’un groupe dans la liste des projets est simplifiée : **Ouvrir la vue d’ensemble** se trouve directement sur la ligne du groupe, et déplier un groupe affiche toujours les sessions de sa vue d’ensemble, même après **Replier tous les projets**.
