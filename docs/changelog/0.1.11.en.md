# Soreno 0.1.11

## What’s new

### Drag and drop files into a terminal

Drop files onto the terminal of a running session to hand them to the agent: their paths are inserted into the input, ready to send.

- Up to 16 files at a time, 32 MiB maximum per file.
- The files are not added to your project: Soreno copies them to a private temporary folder, deleted when the session stops.
- It also works for WSL and SSH projects: on an SSH server, the files are uploaded automatically.

## Changes

- The **Agents** workspace is now called **Projects**.
- In the Git panel, the **Open repository** button is now **Add project**.
- On SSH servers, Soreno now keeps its files in `~/.cache/soreno` instead of `~/.cache/telaoi`. SSH sessions still open from a previous version are not picked up after the update: stop them before updating. You can then delete the old `~/.cache/telaoi` folder on the server.
