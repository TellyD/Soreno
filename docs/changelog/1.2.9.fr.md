# Soreno 1.2.9

## Nouveautés

- Quand vous modifiez la description d’une issue liée à une session, l’agent reçoit le nouveau texte dès que vous faites une pause dans la saisie. Il repartira de cette version s’il doit la modifier à son tour.
- Dans le Chat (OMP) et sur la page mobile, les messages de Soreno à l’agent (commentaire transmis, liaison d’une issue, description mise à jour…) s’affichent en notices repliables, distinctes des messages que vous avez écrits.

## Changements

- Un agent qui modifie la description d’une issue doit dire en une phrase ce qu’il a changé, sans quoi la modification est refusée. Pour une issue locale, cette phrase est publiée en commentaire signé du nom de l’agent.
