# Soreno 0.6.4

## Nouveautés

- **Personnaliser l’icône et la couleur** est aussi proposé dans le menu d’un groupe de projets : icône du catalogue, couleur ou image importée, conservées après un renommage du groupe.

## Changements

- Sous Windows, Ctrl+Retour arrière supprime le mot précédent dans toutes les sessions, locales, WSL ou SSH. Sur macOS, Option+Retour arrière fait de même.
- Sur macOS, Soreno est signé et notarisé par Apple.
- Le bouton **Mobile** de la barre d’état est masqué pour l’instant.
- Sur la page mobile, l’ouverture du clavier est plus fluide sur iOS et Android.
- Dans la vue d’un groupe de projets, le nombre de changements de chaque projet s’affiche sous sa branche.
- Le bouton d’envoi d’un commentaire de ligne garde sa taille quand la fenêtre est étroite.
