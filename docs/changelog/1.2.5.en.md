# Soreno 1.2.5

## What’s new

- In **Design**, the prompt bar accepts images, pasted or dropped. Each one shows in the text as `[Image #N]`, with a thumbnail, and the agent gets the file path at that spot.
- The file editor has a **Wrap lines** button, remembered across sessions.

## Fixes

- A collapsed project group shows the activity of its projects’ sessions.
- A pull with rebase cancelled by a conflict is explained in the interface language: the branch is unchanged, and the conflict is resolved in a terminal with `git rebase`.
