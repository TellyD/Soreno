# Soreno 1.0.0

## What’s new

### Pull requests and merge requests

The Git panel gains a **Pull requests** (GitHub) or **Merge requests** (GitLab) tab for the repository of the `upstream` remote, or `origin` if there is none. It works with github.com and gitlab.com, through the project’s `gh` and `glab` CLIs, locally, in WSL or over SSH. Soreno stores no token: if the CLI is not signed in, **Sign in to GitHub** or **Sign in to GitLab** opens a terminal to authenticate.

- **List**: **Open**, **Mine**, **Review requested** and **Closed / merged** filters, plus search. Each row shows the branches, CI status, review and conflicts. The request for the current branch comes first, marked **Current branch**.
- **Details**: Markdown description, **Checks**, **Commits** and **Files**. Diffs are computed locally by Git. With the panel expanded, **Files** switches to three columns for review.
- **Actions**:
  - **Merge**, offering only the methods the repository allows, and **Merge unverified changes** when checks failed or are still running;
  - **Mark as ready** and **Open in browser**;
  - **Check out in a new worktree**, **Check out in this worktree** and **Close**, in the **…** menu.

The `Ctrl+Shift+M` shortcut (`Cmd+Shift+M` on macOS) expands the Git panel or returns to the terminal, even when the terminal has focus. If the panel is closed, it opens it expanded.

### Auto commit for project groups

In a project group’s Git panel, **Commit** stages every change in each repository, generates a message specific to each repository with Codex, then commits. A failure is reported for its repository without stopping the others. This button replaces the single message shared by all repositories and the group’s **Fetch**.

## Changes

- Deleting a project group can also remove its projects from Soreno, with their launchers and sessions, through a checkbox that is unchecked by default. The folders and their files stay on disk.
- The **Automations** view offers to create an automation from its empty state.
- A truncated option in a dropdown shows its full text on hover.

## Fixes

- A Kanban issue can target a project group’s overview: its agent starts there, without a worktree, including when the issue is scheduled.
- An image inserted in a note stays separated from the text by blank lines, so you can type above and below it.
