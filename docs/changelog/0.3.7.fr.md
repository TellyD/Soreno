# Soreno 0.3.7

## Nouveautés

### Commenter un diff pour l’agent

Sélectionnez des lignes dans le diff de Changements ou dans celui d’un groupe de projets, puis cliquez sur **Commenter** : écrivez une remarque, choisissez l’agent du projet et cliquez sur **Envoyer à l’agent** (ou Ctrl+Entrée). L’agent reçoit la remarque avec le fichier, les lignes concernées et leur extrait à la fin de son tour en cours, sans être interrompu. La fenêtre de commentaire suit l’envoi : **Envoyé**, puis **Livré**, ou **Non livré** avec la raison. Si le diff change entre-temps, Soreno demande de resélectionner les lignes en conservant votre texte. Dans un groupe, le commentaire part à l’agent du groupe.

## Changements

- Quand Soreno ne peut pas arrêter les agents d’un serveur SSH injoignable, fermer un onglet ou supprimer un projet ou un groupe propose **Déconnecter et supprimer** au lieu d’échouer. Tous les projets qui utilisent cette connexion SSH sont alors déconnectés ; les agents encore actifs sur le serveur peuvent continuer de tourner.

## Corrections

- Pendant l’affichage d’un long historique dans le terminal (reprise d’une session Pi, par exemple), la position de lecture est conservée : vous pouvez remonter avec la molette, Maj+Page précédente ou la barre de défilement sans être ramené en bas.
- Le terminal retrouve l’apparence qu’il avait avant la 0.3.6 : fond correct et plus d’ombre en haut quand vous remontez dans l’historique.
