# Soreno 0.7.0

## Nouveautés

### Cadrer un sujet avec `/grill`

Dans le Chat (OMP), `/grill <sujet>` lance un cadrage guidé : OMP explore le code, puis pose ses questions une à une, chacune avec une option recommandée et sa justification, sans modifier de fichier. La colonne **Cadrage** rassemble les décisions au fil des réponses ; vous pouvez répondre librement, revenir sur une décision ou demander la synthèse avec **Synthétiser**.

### Maquettes HTML dans le chat

`/mockup <sujet>`, ou **Maquetter** dans la colonne **Cadrage**, demande à OMP une maquette HTML, affichée dans un aperçu en largeur **Mobile**, **Tablette** ou **Bureau**. Les flèches parcourent les maquettes de la conversation, et **Copier le HTML** la récupère. Un clic sur un élément de la maquette permet de le commenter pour demander une modification. Pendant un cadrage, **Maquetter cette question** illustre chaque option d’une question par une variante, pour y répondre en la regardant.

### Questions annexes

`/btw <question>` pose à OMP une question annexe, même pendant une étape, sans la réorienter ni attendre. La réponse s’affiche en direct dans un panneau au-dessus de la zone de saisie, jamais dans le fil ; le panneau permet de poser une suite ou d’arrêter la question.

### Raccourcis clavier

- **Paramètres** > **Raccourcis** liste les raccourcis de Soreno, avec les touches de votre système ; maintenir une combinaison la met en évidence dans la liste.
- `Ctrl+B` (`Cmd+B` sur macOS) masque ou réaffiche la barre latérale, sans prendre la main sur le gras de l’éditeur ou le terminal.
- `Ctrl+Alt+B` (`Cmd+Option+B` sur macOS) masque ou réaffiche le panneau Git, y compris depuis le terminal.

## Changements

- Les options du diff (**Unifié** ou **Séparé**, **Retour à la ligne**, affichage de la liste des fichiers) sont retenues d’un fichier à l’autre et après un redémarrage. Liste masquée, les actions du fichier affiché (préparer, annuler, résoudre) restent dans la barre du diff.
- Après **Mettre à jour OMP**, **Voir les nouveautés** affiche les nouveautés de la nouvelle version d’OMP.
- **Paramètres** > **Agents** > **Commandes du chat OMP** choisit les commandes proposées par le menu `/` du chat.
- Les blocs de code d’un langage connu sont colorés dans les conversations, le Kanban et les notes de version.
- Les descriptions des options d’une question d’OMP affichent le Markdown, sans liens cliquables à l’intérieur des boutons.
- Une question à choix unique s’envoie avec **Répondre** après avoir choisi l’option, au lieu de partir au premier clic.
- Les messages de commit générés utilisent le modèle par défaut de votre compte Codex quand aucun modèle n’est choisi.

## Corrections

- Dans le Chat (OMP), une connexion SSH perdue est signalée comme telle, au lieu d’un arrêt inattendu d’OMP.
- L’objectif d’une session (`/goal`) s’affiche de nouveau correctement après la reprise d’une conversation.
- En SSH, les dossiers temporaires créés au lancement d’une session sont supprimés quand elle se termine, y compris si elle tournait sans Soreno.
