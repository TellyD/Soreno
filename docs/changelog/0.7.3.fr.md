# Soreno 0.7.3

## Changements

- Dans le panneau Git, **Pull** et **Push** sont toujours visibles dans la barre des fichiers, avec le nombre de commits entrants ou sortants quand il n’est pas nul ; le bouton à utiliser passe en couleur principale, **Pull** en priorité si la branche a divergé. **Pull avec rebase** et le choix du **Dépôt distant** restent dans le menu **Autres actions**.
- Dans le Chat (OMP), **Masquer les tâches terminées** referme la liste de tâches une fois tout terminé ; elle réapparaît dès qu’elle change.
- Dans le Chat (OMP), seules les demandes d’autorisation gardent une icône, au-dessus de la zone de saisie.

## Corrections

- Dans le Chat (OMP), un long message en attente ne déborde plus de la zone de saisie.
