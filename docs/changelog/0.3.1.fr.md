# Soreno 0.3.1

## Changements

- L’entrée **Kanban** se trouve maintenant au-dessus de l’en-tête de la liste des projets, au lieu d’être la première ligne de la liste.
- Quand le panneau Git ne parvient pas à lire un dépôt, le message en donne la cause et la marche à suivre : une autre opération Git est déjà en cours, Git ne répond pas à temps, le dossier du dépôt est inaccessible, ou Git renvoie une réponse inattendue ou trop volumineuse.

## Corrections

- Déplacer le curseur dans une longue note est plus fluide en aperçu intégré : seuls les blocs concernés sont redessinés.
- La liste des projets reste plus réactive avec beaucoup de projets et de sessions.
