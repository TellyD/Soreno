# Soreno 1.3.0

## Nouveautés

- Une session liée à une issue prend le titre de l’issue dans son onglet, à la place du nom du lanceur ou du titre deviné par Claude Code et Codex. Un nom choisi à la main reste prioritaire, et renommer une issue locale renomme sa session.
- Une session de terminal restaurée mais pas démarrée affiche **Cette session n’est pas démarrée.**, avec **Démarrer** ou **Reprendre la conversation** quand une conversation existe.
- Le bouton **Vue par priorités** affiche le nombre de sessions à traiter, jusqu’à 9+, dans la couleur de la plus urgente.

## Changements

- Dans les notes, les dernières lignes peuvent défiler jusqu’au milieu de l’écran.

## Corrections

- Lancer une session locale ou WSL n’attend plus la fin d’un enregistrement de projet.
- Une conversation en cours de démarrage et le dossier d’un groupe WSL ne sont plus affectés par une modification simultanée du projet.
