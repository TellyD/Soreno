# Soreno 1.2.1

## What’s new

- In **Design**, the prompt bar tracks each send: **Sending…**, **Waiting for the agent…**, **The agent is drawing…** during its turn, or **The agent awaits an answer** with **Open logs**. A frame targeted by a prompt is marked until the agent rewrites it or ends its turn.
- Pi is offered as a Design board agent.

## Changes

- A Design board’s agent edits a copy of the current frame instead of rewriting it from memory, so it only changes what is asked. The prompt no longer carries the frame’s HTML, so the size limit is only reached with a very long text.
- A Design board’s agent starts with restricted permissions: no free shell, screenshots or servers. Claude Code and Codex only write to the session’s private folder.
