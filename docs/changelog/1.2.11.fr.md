# Soreno 1.2.11

## Nouveautés

- Dans le panneau Git d’un groupe de projets, l’onglet **Pull requests** ou **Merge requests** réunit les demandes de tous les projets du groupe, des plus récentes aux plus anciennes, et chaque ligne nomme son projet. Les actions s’appliquent au projet de la demande.
- Chaque projet du rail a un bouton **Nouvelle session**, qui ouvre le menu des agents sans passer par les onglets.

## Corrections

- Glisser un projet sous le dernier projet d’un groupe permet de le placer soit dans le groupe, soit juste après lui, et la position visée suit l’en-tête du projet plutôt que le milieu de sa liste de sessions.
- Un projet SSH pas encore connecté se connecte avant la lecture de ses worktrees, par exemple pour créer rapidement un worktree.
- Dans l’éditeur, une ligne à puce dans une citation garde l’indentation de la citation.
