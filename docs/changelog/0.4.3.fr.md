# Soreno 0.4.3

## Nouveautés

### Chat intégré avec votre compte ChatGPT

Nouveau type de session **Chat** dans le menu de création de session : une conversation avec Codex dans une fenêtre de chat, sans terminal ni outil à installer. Elle utilise votre abonnement ChatGPT : connectez-vous une fois avec **Se connecter avec ChatGPT**, ou depuis **Réglages** > **Agents**. Codex travaille dans le dossier du projet ; en WSL et en SSH, ses commandes et ses modifications s’exécutent sur la machine du projet.

- **Autorisations** : par défaut, Codex demande votre accord avant chaque commande et chaque modification de fichier (**Autoriser**, **Tout autoriser dans ce chat**, **Refuser**). **Tout autoriser** supprime ces demandes dans tous les chats jusqu’à ce que vous reveniez à **Demander l’accord**.
- Choix du **Modèle** et du niveau de **Raisonnement**, **Arrêter** pendant une étape, et ajout d’une consigne pendant qu’elle se déroule.
- Une conversation arrêtée se reprend avec **Reprendre la conversation**.

### Démarrer ou arrêter tous les services

Les services d’un projet se lancent tous d’un coup avec **Tout démarrer**, puis s’arrêtent avec **Tout arrêter** une fois qu’ils tournent tous.

## Changements

- Au lancement de Soreno, les projets SSH restent **Non connecté** tant que vous ne les sollicitez pas : aucune lecture automatique (branche, Git, fichiers, services, quotas) n’atteint le serveur, ce qui évite de réveiller un environnement distant facturé. La dernière branche et le dernier état Git connus restent affichés. Lancer une session, y compris depuis une issue Linear, ou cliquer sur **Connecter** rétablit la connexion pour tous les projets de ce serveur.
- Les résumés suivants d’un même agent sur une issue Linear (après une revue ou un commit demandés dans la session, par exemple) prolongent son premier commentaire, sous une seule signature, au lieu d’en publier un nouveau. Ils ne déplacent plus l’issue.
- L’assistant IA des notes et son chat sont retirés. L’onglet **IA** des réglages ne garde que Codex et le modèle des messages de commit.
- **Réglages** s’ouvre désormais depuis le bas de la barre d’icônes, et non plus depuis la barre d’état.

## Corrections

- Le défilement d’un terminal plein de diffs colorés (sessions OMP notamment) ne saccade plus : Soreno déplace les lignes existantes au lieu de tout redessiner.
