# Soreno 1.2.3

## What’s new

- In the project rail, a session can be closed from its row with the **Close tab** button that appears on hover or keyboard focus, without leaving the current project. Pinned sessions don’t have this button.
- In the editor, double-clicking an image opens it in a preview, as does pressing Enter on a selected image.

## Fixes

- Switching views keeps the sidebar hidden with `Ctrl+B`. Clicking the active view again shows it.
- In the Git panel, the scroll bar no longer hides the file actions, notably on macOS.
