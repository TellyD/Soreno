# Soreno 1.4.0

## Nouveautés

### Prototypes interactifs dans Design

L’agent d’un tableau Design peut ajouter un peu de JavaScript à ses cadres pour en faire des prototypes interactifs. Le mode **Interagir avec un cadre** (touche `I`) envoie les clics au prototype au lieu de déplacer les cadres ; Échap ou `I` en sort, et `T` repasse en ciblage d’élément. Les scripts ne chargent rien : réseau, WebRTC et envoi de formulaires restent bloqués, et les aperçus en lecture seule n’exécutent pas les scripts. Un agent de code chargé d’implémenter le tableau reçoit la consigne d’en reproduire aussi les interactions.

### Galerie des tableaux

La vue **Design** s’ouvre sur **Tous les tableaux** : chaque tableau y apparaît en carte, avec une miniature de ses cadres, et s’ouvre d’un clic.

### Effort de raisonnement des tableaux

À la création d’un tableau, on choisit l’effort de raisonnement de son agent, de `low` à `max`, ou **Par défaut de l’agent** pour garder le réglage du CLI.

### Skills des projets dans les groupes

La vue d’ensemble d’un groupe de projets donne accès aux skills de ses projets : Soreno les lie dans `.agents/skills` du dossier du groupe, où OMP et Codex les trouvent.
