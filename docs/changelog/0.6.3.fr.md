# Soreno 0.6.3

## Changements

- Soreno ne garde plus indéfiniment les petits dossiers qu’il crée à chaque lancement d’agent, qui contiennent notamment le dernier message de l’agent, sur le poste comme sur les serveurs SSH : supprimer une session supprime aussi les siens, et ceux qui ne servent plus à la reprise disparaissent après 7 jours sans activité. Le dernier lancement de chaque session et les sessions encore actives sur un serveur sont toujours conservés.
- **Paramètres** > **IA** > **Git** propose un interrupteur **Mode Fast** : activé par défaut comme jusqu’ici, il peut être désactivé pour générer les messages de commit sans le mode Fast de Codex, qui consomme davantage.
- Dans l’onglet **Fichiers**, `Ctrl+V` (`Cmd+V` sur macOS) ou **Coller** dans le menu contextuel copie dans le projet les fichiers copiés depuis l’Explorateur, le Finder ou le gestionnaire de fichiers : dans le dossier ciblé, ou à côté du fichier ciblé. Un nom déjà pris donne `nom copy.ext`, puis `nom copy 2.ext`… Les dossiers ne sont pas collés. Cela fonctionne aussi en WSL et en SSH, avec des fichiers d’au plus 32 Mio en SSH.
- Une issue du Kanban passe dans la colonne en cours dès que son agent démarre, et revient à sa colonne d’origine si le démarrage échoue.
- Le menu **Favoris** des onglets de session est plus large.

## Corrections

- Quand Git refuse de supprimer une branche dont des commits ne sont pas fusionnés, Soreno explique pourquoi et propose de la fusionner ou de la pousser d’abord, au lieu d’un échec générique.
- Le service d’accès mobile installé sur les serveurs inclut désormais le correctif de la 0.6.1 qui affiche les premiers messages d’une conversation dès son ouverture : le dialogue **Mobile** propose **Mettre à jour** sur chaque serveur activé.
