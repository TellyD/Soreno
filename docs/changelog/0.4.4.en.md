# Soreno 0.4.4

## What’s new

### Chat: attachments, commands and editing a message

- **Attachments**: paste, drop or attach with the paperclip images and text files. Codex sees the images, and text files travel with the message, SSH and WSL projects included.
- **Commands**: type `/` for `/new`, `/resume`, `/compact`, `/model`, `/thinking` and `/copy`, with keyboard completion. `/resume` reopens another conversation of the project, for example the one left with **New conversation**.
- **Context N%** shows how full the model’s context is; the **…** menu offers **Compact the conversation** and **New conversation**.
- Hover a message for **Copy**, and on your own messages **Edit from here** or **Send again**, which resume the conversation right before that message.
- A file edit shows its diff, a write shows the written content, and each tool shows how long it ran.
- Chat replies and Linear issues now display Markdown tables.
- The model picked in a chat becomes the model of new chats.

### Chat: specialized agents

The chat can hand part of the work to specialized agents running in the background, with the same tools and approvals as the chat. An **Agents** strip follows them live: **View agent** opens its conversation, where you can **Redirect** a running agent, ask it to **Continue** or **Stop** it. Approval requests name the agent that makes them.

**Manage agents…** in the **…** menu, or `/agents`, opens **Chat agents**, shared by every Soreno chat: enable, edit, create or delete an agent, choose its model, import `.md` files, and set the number of **Concurrent background agents** (1 to 16). Six default agents are offered on first use.

## Changes

- In **Chat agents**, each agent shows the name of the model it actually runs with, and is no longer wrongly flagged as unavailable.
- In **Settings** > **Agents**, the chat row shows right away whether your ChatGPT account is **Connected** or **Not connected**.
- Terminal backgrounds now match the themes: white in light mode, charcoal grey in dark mode.
