# Soreno 1.4.1

## What’s new

- In a pull request’s or merge request’s files, you can comment diff lines and send the comment to the running agent, as in **Changes**. The agent gets the request, its branches and the `git diff` command to look at. From a group overview, the comment names the repository.

## Changes

- Chat (OMP) is adapted up to OMP 19.1:
  - a whole `ask` form shows and is filled in at once, with field checks before sending;
  - the **Auto** thinking level is offered and shown.
