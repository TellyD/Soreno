# Soreno 0.3.0

## What’s new

### Linear Kanban in Projects

A new **Kanban** entry, at the top of the project list, shows your Linear team’s issues in columns, one per status.

- To connect, click **Connect Linear** and paste a Linear personal API key (the **Create an API key** link takes you to the right page). The key is stored in the system keychain. To move cards or edit issues, the key needs the **Write** permission.
- Drag a card to another column to change its status.
- Filter issues with the **Active**, **Backlog** and **All issues** tabs, by team or by Linear project.
- **Disconnect Linear** removes the key.

### Issue details and editing

Click a card to open the issue: description, sub-issues, linked pull requests and activity.

- Edit the title, status, priority, assignee, labels and project right in Soreno.
- Add a comment with **Comment**.
- **Open in Linear** opens the issue in your browser.
- **Back to issues**, or your mouse’s back button, returns to the Kanban.

### Create issues

A column’s **+** button creates an issue directly in that status; the **New issue** button in the Kanban toolbar creates it in the first “to do” status. Fill in the title, description and properties, then click **Create issue**. Check **Create more** to add several issues in a row without closing the dialog.

### Start an agent on an issue

In an issue’s details, the **Soreno** section lets you hand the issue to an agent:

- Choose the Soreno project and the agent, then click **Start agent**. The agent receives the issue’s title, link and description.
- With **Worktree** checked (the default), Soreno first creates a worktree on the branch Linear suggests for this issue.
- If the issue has not started yet, it automatically moves to the “in progress” status.
- An issue has only one agent session: afterwards, **Open session** takes you straight back to it.

### Link a Soreno project to a Linear project

In a project’s form, the **Linear project** field links the Soreno project to a Linear project. Kanban cards of that Linear project then show a shortcut that opens the Soreno project.

### Activity on collapsed projects

A collapsed project in the list now shows the number of active agents next to its name, with an animated indicator when one of them is working.

## Fixes

- A terminal opened late or lagging behind gets a complete screen back, even after hours of use, instead of a partial display.
- Switching branches is no longer wrongly blocked by a session on another SSH repository when Soreno cannot identify that session’s server.
- In a group’s **Overview**, the repository status is aligned with the title.
