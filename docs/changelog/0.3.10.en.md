# Soreno 0.3.10

## What’s new

### Linear: the agent moves the issue to review with its summary

An agent started from a Linear issue ends its work with a summary. Soreno posts it as a comment on the issue and moves the issue to its team’s review state (the first started state whose name contains “review” or “revue”). An issue that is already done or canceled keeps its state.

### Linear: ask an agent to create an issue

When a Linear API key is saved, you can ask any agent (Claude Code, Codex, Pi, OMP) to create a Linear issue. Soreno creates it with your key, in the team of the Linear project linked to the project or otherwise in the first team, then announces it with a notification offering **Open**. The agent only creates an issue when you ask it to.

### Codex and Claude quotas: a panel per account

Quotas in the status bar are shown as meters. Clicking them opens the **Usage** panel: one card per account with its plan, masked email address and environments (Local, WSL, SSH), the **Short window** and **Long window** with their reset and elapsed time, and Claude’s per-model caps (Opus, Sonnet…). **Show in the status bar** chooses the account displayed. An unavailable quota is no longer shown as 0%.

## Changes

- The agent section of a Linear issue’s detail is more compact: the agent and project choice is summarized on one line, editable with **Change**; the worktree option is now **Work in a dedicated worktree**. An agent that has finished its turn shows as **Idle**, and the end of a session is shown in a few words (**Session deleted**, **Worktree removed**, **Merged into** the branch, **Project removed**).

## Fixes

- An agent started in the background, whose terminal isn’t shown yet, no longer gets stuck at startup waiting for a terminal reply.
