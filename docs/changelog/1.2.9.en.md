# Soreno 1.2.9

## What’s new

- When you edit the description of an issue linked to a session, the agent gets the new text as soon as you pause typing. It will start from that version if it has to edit it in turn.
- In Chat (OMP) and on the mobile page, Soreno’s messages to the agent (forwarded comment, linked issue, updated description…) show as collapsible notices, apart from the messages you wrote.

## Changes

- An agent that edits an issue’s description must say in one sentence what it changed, otherwise the edit is refused. For a local issue, that sentence is posted as a comment signed with the agent’s name.
