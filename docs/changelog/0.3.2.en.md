# Soreno 0.3.2

## What’s new

### Pin session tabs

Right-click a session tab, then **Pin tab**: the tab moves to the front, becomes more compact and loses its close button. A pinned tab cannot be closed or deleted until you unpin it. Pinned tabs are kept on the next launch.

### Image previews in Git diffs

When an image in the repository changes, the diff shows the image before and after the change, instead of the “Binary content cannot be displayed.” message.

### Linear: more actions from Soreno

- **Edit description** of an issue right from its details.
- **Delete issue** from its details. It goes to Linear’s trash, where you can restore it for 30 days. The linked agent session is kept in Soreno.
- **Disconnect Linear** now asks for confirmation.

### Linear: background agents

- Starting an agent on an issue no longer takes you away from the Kanban: the agent starts in the background. Check **Open its terminal once started** to go straight to it.
- The issue’s card and details show its agent’s activity: working, waiting for your reply, stopped.
- Closing an agent’s session no longer unlinks it from its issue: **Reopen session** relaunches it from the issue.
- When the session, its worktree or its project is gone, the issue shows how it ended (session deleted, worktree merged or deleted, project removed) and you can start a new agent.
- The Soreno project picker shows each project’s icon, environment (local, WSL, SSH) and path.

## Changes

- In very large repositories (more than 10,000 changes), the Git panel pauses its automatic refresh and tells you. Click **Refresh** to reread the repository on demand.
- When **Merge into \<main branch\> and delete** fails, the message now gives the exact reason instead of a generic error: a Git operation already in progress, an unreachable linked project, a missing main worktree, and so on.
- The visible terminal is drawn with the graphics card, so it stays smooth during heavy output.

## Fixes

- If Claude Code or Codex cannot save its conversation tracking (full disk, remote server unavailable…), the agent keeps working; only that turn’s activity tracking is lost.
