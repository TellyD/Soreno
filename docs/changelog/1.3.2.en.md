# Soreno 1.3.2

## What’s new

- A Kanban issue can target a group overview that was never opened: overviews are offered ahead of the projects, and Soreno prepares the chosen one before attaching the issue or starting its agent there.

## Changes

- Project lists in forms (Kanban, Design, automations, SSH connection) are sorted by name.
- A group’s dialog shows one machine’s projects at a time and saves only those, so all projects of a group stay on the same machine.
- An agent’s pending issue requests are handled one after another, without waiting between each.

## Fixes

- An unsent comment or an unsaved description is kept when an issue is closed and reopened, including when sending fails after closing.
- In an SSH project form, typing a host that matches an existing project no longer closes the field being edited, and **Edit connection** reopens the connection details.
- In **Design**, the dark theme no longer flashes white when a frame shows again.
