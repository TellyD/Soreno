# Soreno 1.2.12

## What’s new

- Kanban issues can be sorted by **Created**, **Last updated** or **Priority**, in either order with **Reverse sort order**. The chosen sort is remembered.

## Changes

- Switching branches no longer requires a clean working tree: local changes carry over to the target branch, and Git refuses the switch only if they would be overwritten.
- A disconnected or not-yet-connected SSH project explains it where you look at it: Git panel, files, services, sessions and groups, with a way to connect it. A group names its disconnected projects instead of leaving them out.
- On the mobile page, an unavailable camera can be retried while scanning.

## Fixes

- A file opened with quick open is revealed in the project tree.
- A folder expanded and then deleted outside Soreno disappears from the tree on refresh, without an error.
- A coding agent linked to a Design board draws in that board, even an empty one, and its frames no longer go to the previous board after the link changes.
