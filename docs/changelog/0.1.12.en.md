# Soreno 0.1.12

## Changes

### One place for errors

Errors, validation messages and warnings now all appear in the same place: a notification in the bottom-right corner of the window, instead of messages scattered across each panel.

- Errors are red and warnings amber; a repeated problem is shown only once, with a counter.
- Notifications close on their own after a few seconds; hovering over a notification pauses it. Notifications offering an action, such as **Retry**, stay visible until you close them.
- Messages are always written in the interface language: raw technical output (Git, SSH, Codex…) is no longer displayed. This also applies to file explorer errors.

### Guided SSH connection

Adding an SSH project is easier:

- Enter the server and the account, then click **Choose a folder…**. For a server you already trust, its folders show up directly.
- For a new server, Soreno shows its fingerprint. Compare it with the one given by the administrator or the server console, then confirm: the folders open right away. If you cancel, nothing is remembered.
- If the server key has changed, Soreno blocks the connection and does not offer to replace it automatically.
- If you pick the `.pub` file instead of the private key by mistake, Soreno explains why.
- When the connection fails, the message tells you what to check: account, private key, network or firewall. If your key is protected by a passphrase and not loaded in the SSH agent, Soreno asks you to load it with `ssh-add`.
- The same steps apply when you open or clone a repository on an SSH server.

### SSH session history is kept

Reattaching an SSH session, after closing Soreno or losing the connection, now restores the whole terminal history, including what the agent printed in the meantime: you can scroll back through a Claude Code, OMP, Pi, Codex or shell session again. Multi-line pastes and the mouse keep working after reattaching. Sessions started with an earlier version get this behaviour after their next restart.

### Faster commit messages

Commit message generation now uses Codex fast mode and answers sooner.

### Other changes

- The **Explorer** tab in the side panel is now called **Files**. The current branch and how far ahead or behind the remote it is stay visible while this tab is open.
- During a Git operation (staging, restoring…), the list of changed files and the diff stay on screen instead of disappearing.
- Adding a project that is already in the list no longer creates a duplicate: Soreno selects the existing project.

## Fixes

- The agent activity indicator now stops when the CLI stops working, even if the CLI did not report it: a Claude Code turn interrupted with Esc or a pending permission request no longer leaves it spinning forever.
- The status bar only shows the vault and the note save status in the **Notes** workspace. The local vault name is also translated when the interface is in English.
- Reading Git changes in WSL projects is more reliable, including for large files.
