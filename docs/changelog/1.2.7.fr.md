# Soreno 1.2.7

## Nouveautés

- Le Kanban peut se connecter à plusieurs workspaces Linear, chacun avec sa propre clé d’API. **Ajouter un workspace…** en connecte un autre depuis le menu Linear, et chaque workspace se déconnecte séparément. Les issues d’un agent vont au workspace lié au projet de sa session. La clé d’une version précédente est conservée.

## Changements

- Un tableau Design transmis à un agent de code est décrit dans un fichier `design-board.md` joint, qui liste ses écrans. Le prompt ne fait plus que renvoyer vers ce fichier.
- Dans la **Vue par priorités**, les sessions suivent l’ordre de l’arborescence des projets.

## Corrections

- Sous Linux, fermer un onglet d’un clic du milieu ne colle plus la sélection primaire dans le terminal.
