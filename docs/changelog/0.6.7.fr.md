# Soreno 0.6.7

## Nouveautés

### Chat (OMP) plus complet

- **Mentions et commandes** : `@` propose les fichiers du projet, les récents d’abord ; `/` propose les commandes d’OMP et les skills. Flèches, **Entrée** ou **Tab** insèrent la suggestion, **Échap** ferme la liste.
- **Pièces jointes** : collez, déposez ou choisissez avec le trombone n’importe quel fichier. Les images partent avec le message si le modèle les lit, les fichiers texte sont recopiés dans le message, et tout autre fichier est transféré dans le dossier privé de la conversation, comme dans un terminal.
- **Messages en attente** : un message envoyé pendant une étape attend son tour et peut être annulé ; arrêter l’étape remet les messages en attente dans la zone de saisie.
- **Masquer les outils et le raisonnement**, dans le menu **…**, ne laisse que les réponses ; ce choix vaut pour toutes les conversations et est mémorisé.
- **Mettre à jour OMP** apparaît quand une version plus récente d’OMP est disponible dans l’environnement du projet.
- Les sous-agents en cours s’affichent au-dessus de la zone de saisie, avec leur type.
- Une conversation reçoit un titre comme dans le terminal d’OMP, repris comme nom de la session.
- Dans une question d’OMP, la réponse conseillée est marquée **Recommandé**, et la session apparaît en attente de réponse tant que la question est ouverte.
- **Résoudre avec un agent**, après un conflit de fusion d’un worktree, ouvre une nouvelle conversation **Chat (OMP)** quand c’est l’agent de ce worktree.

## Changements

- Le chat reste en démarrage jusqu’à ce qu’OMP réponde, au lieu de sembler prêt trop tôt.
- Les longs avis d’OMP sont repliés dans la conversation.
- Une liste de tâches à une seule phase n’affiche plus le titre « Tasks ».

## Corrections

- Dans les conversations, le Kanban et les notes de version, les éléments d’une liste Markdown séparés par une ligne vide restent dans la même liste.
