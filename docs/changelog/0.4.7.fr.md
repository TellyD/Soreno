# Soreno 0.4.7

## Nouveautés

### Actions sur les fichiers

Dans l’onglet **Fichiers** du panneau Git, un clic droit sur un fichier ou un dossier (ou la touche Menu, ou Maj+F10) ouvre ses actions :

- **Copier le chemin relatif** ou **Copier le chemin absolu**, et **Insérer le chemin dans** un agent actif du projet, qui s’affiche avec le chemin saisi dans son terminal.
- **Voir les changements** d’un fichier modifié, et **Voir l’historique** limité à ce fichier ou ce dossier.
- **Nouveau fichier…**, **Nouveau dossier…**, **Renommer ou déplacer…** (les dossiers manquants sont créés), **Dupliquer** et **Supprimer…**. La suppression est toujours confirmée et définitive, sans passer par la corbeille ; un nom déjà pris est refusé.

Le menu **Autres actions sur les fichiers** de la barre de l’arbre permet aussi de **Révéler le fichier ouvert** et de **Tout replier**. Chaque fichier modifié affiche son statut Git, et les dossiers qui contiennent des changements une pastille. Ces actions fonctionnent en local et en SSH.

## Changements

- **Ouvrir** dans la notification d’une issue créée par un agent affiche l’issue dans le Kanban de Soreno, au lieu de l’ouvrir dans le navigateur.
- Dans le détail d’une issue Linear, le formulaire pour démarrer un nouvel agent est séparé par un trait de la dernière session.
- La vue d’ensemble d’un groupe de projets n’affiche plus le résumé des changements quand il n’y en a aucun.

## Corrections

- La recherche rapide de fichiers ne renvoie plus de résultats périmés après qu’un dossier a cessé d’être un dépôt Git.
