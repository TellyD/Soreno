# Soreno 1.3.6

## Fixes

- Since Claude Code 2.1.326, Claude no longer asks to trust the session’s private folder, where Soreno drops its messages and the agent writes its issue requests.
- On Linux, updating an `.rpm` install works on Fedora 45 and later: RPM 6 refused the package because it has no GPG signature. Soreno still checks the update’s signature before installing it, which asks for the administrator password. An earlier `.rpm` install cannot update itself to this version on Fedora 45: install the 1.3.6 `.rpm` by hand.
