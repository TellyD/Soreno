# Soreno 0.2.0

## What’s new

### Add several SSH projects at once

When adding an SSH project, check **Select multiple projects** in the server’s folder list, then check the folders you want: each one becomes a project.

- Check **Create a group with the selected projects** to put them in a new group right away. The group name is suggested from the parent folder, and you can change it.
- The confirm button shows how many projects are selected.

### Diff minimap

Diffs in the **Changes** and **History** views now have a minimap on the side. It shows where additions and deletions are in the file, and which part is currently displayed. Click or drag in the minimap to move around.

### Show only projects with agents

The new **View options** menu in the project list brings together:

- **Only projects with agents**, which hides projects without an agent session. A banner at the bottom of the list shows how many projects are hidden, with a **Show all** button. This choice is kept on the next launch.
- **Collapse all projects** / **Expand all projects**, which used to be a separate button.

## Changes

- Browsing an SSH server’s folders is clearer: **Select this folder** confirms the folder shown, and **Back** closes the list without changing anything. The SSH form also shows less help text.
- Switching branches is no longer blocked by a running service or by an agent in another worktree. Only an agent working in the same worktree blocks the switch, and the message tells you which one to stop.
- A disconnected SSH project or a session on another server no longer blocks Git operations in other projects.
- The worktree deletion confirmation now states that unmerged local commits on its branch will be deleted.
- Git warnings now show Git’s exact message instead of generic text.
- A group’s **Overview** lists its projects in the same order as the project list.
- In a group form, a project that cannot join the group now says so clearly.
- The add project icon is larger.

## Fixes

- If a worktree’s branch gets a new commit while the worktree is being deleted, the branch is kept instead of being deleted.
- Worktrees of a bare repository can be deleted; merging them is still refused.
- The worktree dialog locks after a Git error with an uncertain result, to avoid a second operation on an unknown state.
- The background of the selected **Overview** now displays correctly.
