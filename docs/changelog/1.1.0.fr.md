# Soreno 1.1.0

## Nouveautés

### Messages aux agents plus fiables

- Les messages de Soreno à un agent, comme un commentaire transmis, la liaison d’une issue ou un commentaire de diff, attendent que le texte tapé dans son terminal soit validé par Entrée ou abandonné par `Ctrl+C`. Sans cela, ils s’y ajouteraient. Le message affiche alors **en attente : saisie en cours dans le terminal de l’agent**.
- Claude Code et Codex ne reçoivent plus rien pendant leurs écrans de démarrage (confiance du dossier, revue des hooks), où une Entrée pouvait choisir une option, souvent quitter.
- Une issue peut être liée ou déliée d’une session arrêtée. Le message attend le prochain démarrage de la session, même après la fermeture de Soreno.
- Quand un agent remplace la description d’une issue locale, l’ancienne description est d’abord ajoutée en commentaire.
- Dans la vue d’ensemble d’un groupe, Codex reçoit lui aussi la liste des dépôts du groupe.

### Recherche dans tout un groupe

Depuis la vue d’ensemble d’un groupe de projets, `Ctrl+P` et `Ctrl+Maj+F` (`Cmd` sur macOS) cherchent dans tous les projets connectés du groupe, avec les résultats préfixés par le nom du projet. Un projet en erreur ne masque pas les autres. Choisir un résultat sélectionne le projet et ouvre le fichier dans **Fichiers**.

## Changements

- Les notifications d’information disparaissent seules, même quand elles proposent une action comme **Ouvrir**.

## Corrections

- Le Kanban nomme les sessions d’agent comme leurs onglets : nom personnalisé, sinon nom de la conversation, sinon titre du terminal.
