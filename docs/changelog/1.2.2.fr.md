# Soreno 1.2.2

## Nouveautés

- Soreno est aussi publié en paquet `.rpm` pour Linux (Fedora 39 ou plus récent). Sur Fedora, il est préférable à l’AppImage, qui embarque sa propre pile WebKitGTK.
- Les installations `.deb` et `.rpm` se mettent désormais à jour automatiquement, comme l’AppImage. L’installation de la mise à jour demande le mot de passe administrateur.

## Changements

- Un agent lancé depuis une issue dont la description est trop longue pour le prompt ne reçoit plus une description tronquée : il lui est demandé de lire d’abord `issue.md`, qui contient l’issue entière.

## Corrections

- Dans les messages et les conversations, une adresse web écrite telle quelle devient un lien sans la ponctuation finale ni une parenthèse fermante non appariée.
