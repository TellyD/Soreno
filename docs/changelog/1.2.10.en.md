# Soreno 1.2.10

## What’s new

- **Agent text size**, in the appearance settings, enlarges or shrinks the text of agent terminals and conversations, from 80% to 150%. In the agents view, `Ctrl+=` enlarges it, `Ctrl+-` shrinks it and `Ctrl+0` resets it to 100% (`Cmd` on macOS).
- Each agent can have **default arguments**, in the agent settings, added when its new sessions start.

## Fixes

- The warning for a CLI that does not report its activity also gives the likely cause for an up-to-date Claude Code: the `CLAUDE_CODE_DISABLE_TERMINAL_TITLE` variable, to remove from its environment or `settings.json`.
- Loading spinners no longer wobble on macOS, and the Kanban refresh button uses the same spinner as the rest of the interface.
