# Soreno 1.2.6

## What’s new

- The **Priority view** button in the project rail sorts sessions into two sections: **To handle**, first the sessions awaiting an answer, then those with an unread turn, and **In progress** for the other running sessions. The chosen view is remembered.

## Changes

- The rail’s **Collapse all** and **Expand all** buttons apply to groups as well as projects.
- Hover backgrounds are subtler in the light theme.

## Fixes

- In **Design**, a pasted or dropped image stays in the draft until it is sent, even if the agent restarts in the meantime. A file that is not PNG, JPEG, GIF or WebP is refused with a message.
