# Soreno 0.4.8

## Nouveautés

### Accès mobile aux sessions SSH

Suivez et pilotez depuis votre téléphone les agents de vos serveurs SSH (Pi, OMP, Claude Code, Codex), même quand cet ordinateur est éteint. Le dialogue **Mobile** de la barre d’état, à côté de **Ports**, vérifie les prérequis (serveur Linux compatible, Tailscale connecté sur le serveur, publication HTTPS) en indiquant la commande à lancer pour chacun, puis **Activer l’accès mobile** installe le service sur le serveur et affiche l’adresse à ouvrir sur le téléphone, avec un QR code. Plusieurs serveurs peuvent être activés : un serveur principal regroupe les sessions de tous les autres sur la même page. Sur le téléphone, la page liste les sessions, affiche chaque conversation avec ses outils et permet d’envoyer un message à l’agent, sans changer la taille du terminal sur l’ordinateur.

Dans un onglet de session SSH, **Copier la commande de rattachement** donne aussi la commande qui rejoint cette session depuis un autre terminal ou un client SSH mobile.

### Gérer les skills

Nouvelle page **Skills** dans les réglages : elle liste les skills installés pour vos agents, globalement et dans chaque projet, sur cet ordinateur, dans WSL et sur vos serveurs SSH. Filtrez la liste, supprimez un skill, et mettez à jour ceux installés depuis skills.sh quand leur dépôt a changé (**Mise à jour disponible**, **Tout mettre à jour**). Un projet ou un serveur déconnecté est signalé sans ouvrir de connexion SSH.

## Changements

- **Insérer le chemin dans l’agent actif** remplace le choix d’un agent dans le menu de l’onglet **Fichiers** : le chemin va à l’agent du volet actif.
- L’indicateur d’usage de la barre d’état affiche l’usage de la semaine, et non plus la fenêtre la plus chargée.
- Le **Journal du terminal** enregistre aussi la cause détaillée des lectures Git en échec.

## Corrections

- Après une mise en veille ou un changement de réseau, le panneau Git d’un projet SSH n’affiche plus « dossier du dépôt injoignable » : la lecture est relancée une fois sur une nouvelle connexion.
- Quand le fichier affiché dans Changements n’est plus modifié, le panneau Git se met à jour au lieu d’afficher une erreur.
- Le curseur du terminal reste fixe pendant la saisie et ne clignote qu’au repos.
- Codex lancé par Soreno n’affiche plus d’avertissement sur l’absence de son serveur partagé.
