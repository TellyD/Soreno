# Soreno 0.3.4

## Nouveautés

### Linear : images dans une nouvelle issue

Dans **Nouvelle issue**, ajoutez des images à la description avec **Ajouter des images**, en les collant ou en les déposant dans le champ. Elles sont envoyées à Linear et insérées dans la description à l’emplacement du curseur. Seules les images sont acceptées, jusqu’à 25 Mo chacune.

## Changements

- **Fusionner dans \<branche principale\> et supprimer** et la suppression d’un worktree arrêtent les sessions de ce worktree avant toute modification Git. Si une session ne peut pas être arrêtée (connexion SSH perdue, par exemple), rien n’est modifié et le message l’indique.
- Quand une fusion est encore en cours dans le worktree source, **Fusionner dans \<branche principale\> et supprimer** l’explique et demande de la commiter dans Changements, au lieu d’un échec générique.

## Corrections

- Un projet dont le dossier a été supprimé n’empêche plus la liste des projets de regrouper les worktrees à jour.
- Dans les descriptions et commentaires Linear et les réponses de l’assistant, un lien d’image n’affiche plus de `!` devant son texte.
