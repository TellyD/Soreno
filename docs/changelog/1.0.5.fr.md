# Soreno 1.0.5

## Nouveautés

- `Ctrl+Maj+W` (`Cmd+W` sur macOS) ferme l’onglet de session actif, même quand le terminal a le focus. Un onglet épinglé n’est pas fermé. Sur macOS, **Close Tab** remplace **Close Window** dans le menu, pour que `Cmd+W` ne ferme plus l’application.
- Un agent peut modifier le titre ou la description de l’issue liée à sa session, locale ou Linear, si vous le lui demandez explicitement. L’issue affichée est rechargée, et une description en cours de saisie dans Soreno n’est pas remplacée.
- Depuis la vue d’ensemble d’un groupe de projets, le `@` de Claude Code, Codex, Pi et OMP propose les fichiers des dépôts du groupe, sous `<dépôt>/…`. Soreno place pour cela un lien vers chaque dépôt dans le dossier du groupe.

## Corrections

- Le panneau de droite retient pour chaque session s’il affiche son issue ou les outils du projet.
- Dans l’aperçu en direct de l’éditeur, les puces, cases à cocher et numéros des listes sont alignés, et les sous-listes partent sous le texte parent. Un titre ou un bloc collé au bloc précédent, sans ligne vide, en est espacé.
