# Soreno 1.2.12

## Nouveautés

- Les issues du Kanban se trient par **Création**, **Mise à jour** ou **Priorité**, dans l’ordre voulu grâce à **Inverser l’ordre de tri**. Le tri choisi est mémorisé.

## Changements

- Changer de branche n’exige plus une copie de travail propre : les modifications locales suivent sur la branche cible, et Git refuse le changement seulement si elles seraient écrasées.
- Un projet SSH déconnecté ou pas encore connecté l’explique là où on le consulte : panneau Git, fichiers, services, sessions et groupes, avec la possibilité de le connecter. Un groupe nomme ses projets déconnectés au lieu de les ignorer.
- Sur la page mobile, une caméra indisponible pendant le scan peut être réessayée.

## Corrections

- Un fichier ouvert par l’ouverture rapide est révélé dans l’arborescence du projet.
- Un dossier déplié puis supprimé hors de Soreno disparaît de l’arborescence au rafraîchissement, sans erreur.
- Un agent de code lié à un tableau Design dessine dans ce tableau, même vide, et ses cadres ne partent plus dans l’ancien tableau après un changement de liaison.
