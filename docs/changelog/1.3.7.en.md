# Soreno 1.3.7

## What’s new

- When Soreno restarts, a local terminal gets back its previous output and working directory. A directory deleted in the meantime falls back to the project’s.
- Local bash and zsh terminals have a command history per project, kept across sessions and deleted with the project. A `HISTFILE` you set yourself still takes precedence.

## Changes

- A session’s end-of-task report replaces its previous report on the issue, as long as that one was not edited by hand; otherwise a new comment is posted.
- Chat (OMP) is adapted up to OMP 19.0.0: `ask` forms show each field’s context and the checked state of options.

## Fixes

- In Chat (OMP) questions, Enter checks a checkbox option, and the selected option stays visible.
