# Soreno 0.7.7

## What’s new

- **Soreno on Linux:** the release ships an AppImage and a `.deb` package for x86_64 (glibc 2.35 and WebKitGTK 4.1 or newer, i.e. Ubuntu 22.04, Debian 12 or later). The AppImage updates itself, like the Windows and macOS versions.
- On Linux, agent notifications go through the desktop (GNOME, KDE Plasma…) and clicking one opens its session; the KDE Plasma task manager, Ubuntu Dock and Dash to Dock show how many sessions are waiting for you.
- On Linux, the Linear API key is kept in the session keyring (GNOME Keyring or KWallet). Without a reachable keyring, connecting to Linear says so instead of forgetting the key on restart.
- **Download…**, in the context menu of a file in the **Files** tab, saves a copy of the file wherever you choose on your computer, including from a WSL or SSH project (8 MiB max over SSH).

## Changes

- The project form no longer reports WSL discovery as unavailable on macOS: WSL is simply not offered there.
- The **URLs** tab of SSH projects is removed.
- Visual touch-ups: commits to push or pull counted without a badge in the Git panel, folded diff lines without a margin.
