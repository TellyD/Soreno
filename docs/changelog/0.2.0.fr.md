# Soreno 0.2.0

## Nouveautés

### Ajouter plusieurs projets SSH d’un coup

Lors de l’ajout d’un projet SSH, cochez **Sélectionner plusieurs projets** dans la liste des dossiers du serveur, puis cochez les dossiers voulus : chacun devient un projet.

- Cochez **Regrouper les projets sélectionnés** pour les réunir aussitôt dans un nouveau groupe. Le nom du groupe est proposé à partir du dossier parent, et vous pouvez le modifier.
- Le bouton de validation indique le nombre de projets sélectionnés.

### Minimap des diffs

Les diffs des vues **Changements** et **Historique** ont maintenant une minimap sur le côté. Elle montre où se trouvent les ajouts et les suppressions dans le fichier, ainsi que la partie actuellement affichée. Cliquez ou faites glisser dans la minimap pour vous déplacer.

### Afficher seulement les projets avec agents

Le nouveau menu **Options d’affichage** de la liste des projets regroupe :

- **Uniquement les projets avec agents**, qui masque les projets sans session d’agent. Un bandeau en bas de la liste indique combien de projets sont masqués, avec un bouton **Tout afficher**. Ce choix est conservé au prochain lancement.
- **Replier tous les projets** / **Déplier tous les projets**, qui était auparavant un bouton à part.

## Changements

- Le parcours des dossiers d’un serveur SSH est plus clair : **Sélectionner ce dossier** valide le dossier affiché, et **Retour** referme la liste sans rien changer. Le formulaire SSH affiche aussi moins de texte d’aide.
- Changer de branche n’est plus bloqué par un service en cours ni par un agent d’un autre worktree. Seul un agent qui travaille dans le même worktree bloque le changement, et le message indique lequel arrêter.
- Un projet SSH déconnecté ou une session sur un autre serveur ne bloque plus les opérations Git des autres projets.
- La confirmation de suppression d’un worktree précise que les commits locaux non fusionnés de sa branche seront supprimés.
- Les avertissements Git affichent maintenant le message exact de Git, au lieu d’un texte générique.
- La **Vue d’ensemble** d’un groupe liste ses projets dans le même ordre que la liste des projets.
- Dans un formulaire de groupe, un projet qui ne peut pas rejoindre le groupe l’indique clairement.
- L’icône d’ajout de projet est plus grande.

## Corrections

- Si la branche d’un worktree reçoit un nouveau commit pendant sa suppression, elle est conservée au lieu d’être supprimée.
- Les worktrees d’un dépôt nu (bare) peuvent être supprimés ; leur fusion reste refusée.
- La fenêtre de worktree se bloque après une erreur Git au résultat incertain, pour éviter une deuxième opération sur un état inconnu.
- Le fond de la **Vue d’ensemble** sélectionnée s’affiche correctement.
