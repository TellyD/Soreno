# Soreno 0.1.9

## What’s new

### SSH port forwarding

The new **Ports** button in the status bar of an SSH project lets you open a service running on the remote server (development server, web app…) in your browser.

- Enter one or more ports, or a range such as `8088:8095`.
- If a port is already in use on your computer, Soreno picks another one and tells you which.
- **Open** launches the service in your browser; **Stop all** stops every forwarded port.
- Forwarded ports stop when you disconnect the project or quit Soreno.

### SSH sessions survive closing Soreno

Quitting Soreno no longer stops your sessions on an SSH server: reopen them and you are back in the terminal where you left off, agent included. To really end a session, use **Stop**.

To make this possible, Soreno automatically installs a small utility (`dtach`) in `~/.cache/soreno` on the server. It does not need administrator rights and works on Linux and macOS, on both Intel/AMD and ARM processors.

### Quick file open

`Ctrl+P` (or `Cmd+P` on macOS) opens a file search for the project. Type a few letters of the name to find a file. Files ignored by Git are left out. It also works for WSL and SSH projects.

### Merge a worktree and delete it

A new action, **Merge into \<main branch\> and delete**, wraps up the work done in a worktree in one step. It is available in the **Branches** view, or by right-clicking the worktree in the project list.

- The worktree’s changes are brought into the main branch, then the worktree and its branch are deleted.
- If there is a conflict, the main branch is left untouched: resolve the conflict in the worktree, commit, then run the action again.
- If the worktree or the main repository has uncommitted changes, Soreno tells you which one to fix.
- If sessions are running in the worktree, the confirmation lists them and Soreno stops them before merging.

### Quick worktree creation

The `+` button on a project in the sidebar creates a worktree from the current branch. The new worktree shows up in the list right away.

### Edit more files

The project explorer now lets you edit any text file, whatever its extension.

## Fixes

- After switching branches, the branch shown in the project list updates right away.
- A session open in another environment (for example on an SSH server) no longer prevents switching branches in a local project.
- If deleting a branch fails, you can now try again.
- The SSH terminal displays correctly when you reopen a session.
- Worktrees no longer appear briefly and then vanish from the project list.

## Interface

- The project list shows more clearly which branches and worktrees belong to which project.
- The selected session stands out more in the sidebar.
- Confirmation dialogs have the same style everywhere.
- Changed-file markers and error messages in the Git panel are easier to read.
- The add project button is always visible.

## Translations

- Error messages are now shown in your chosen language (French or English) throughout the app: assistant, vaults, note types, agents, Git panel, services and SSH projects.
