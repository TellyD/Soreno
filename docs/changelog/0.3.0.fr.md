# Soreno 0.3.0

## Nouveautés

### Kanban Linear dans Projets

Une nouvelle entrée **Kanban**, en haut de la liste des projets, affiche les issues de votre équipe Linear en colonnes, une par statut.

- Pour vous connecter, cliquez sur **Connecter Linear** et collez une clé d’API personnelle Linear (le lien **Créer une clé d’API** mène à la bonne page). La clé est conservée dans le trousseau du système. Pour déplacer des cartes ou modifier des issues, la clé doit avoir la permission **Write**.
- Déplacez une carte d’une colonne à l’autre pour changer son statut.
- Filtrez les issues avec les onglets **Actives**, **Backlog** et **Toutes les issues**, par équipe ou par projet Linear.
- **Déconnecter Linear** retire la clé.

### Détail et modification des issues

Cliquez sur une carte pour ouvrir l’issue : description, sous-issues, pull requests liées et activité.

- Modifiez le titre, le statut, la priorité, le responsable, les labels et le projet directement dans Soreno.
- Ajoutez un commentaire avec **Commenter**.
- **Ouvrir dans Linear** ouvre l’issue dans le navigateur.
- **Retour aux issues**, ou le bouton « précédent » de la souris, ramène au Kanban.

### Créer des issues

Le bouton **+** d’une colonne crée une issue directement dans ce statut ; le bouton **Nouvelle issue** de la barre du Kanban la crée dans le premier statut « à faire ». Renseignez le titre, la description et les propriétés, puis **Créer l’issue**. Cochez **Créer à la suite** pour enchaîner plusieurs issues sans refermer la fenêtre.

### Lancer un agent sur une issue

Dans le détail d’une issue, la section **Soreno** permet de confier l’issue à un agent :

- Choisissez le projet Soreno et l’agent, puis cliquez sur **Démarrer l’agent**. L’agent reçoit le titre, le lien et la description de l’issue.
- Avec **Worktree** coché (par défaut), Soreno crée d’abord un worktree sur la branche proposée par Linear pour cette issue.
- Si l’issue n’a pas encore commencé, elle passe automatiquement au statut « en cours ».
- Une issue n’a qu’une session d’agent : ensuite, **Ouvrir la session** y retourne directement.

### Lier un projet Soreno à un projet Linear

Dans le formulaire d’un projet, le champ **Projet Linear** associe le projet Soreno à un projet Linear. Les cartes Kanban de ce projet Linear affichent alors un raccourci qui ouvre le projet Soreno.

### Activité des projets repliés

Un projet replié dans la liste affiche maintenant le nombre d’agents actifs à côté de son nom, avec un indicateur animé quand l’un d’eux travaille.

## Corrections

- Un terminal ouvert tardivement ou resté en retard retrouve un écran complet, même après plusieurs heures de session, au lieu d’un affichage partiel.
- Changer de branche n’est plus bloqué à tort par une session sur un autre dépôt SSH quand Soreno ne parvient pas à identifier le serveur de cette session.
- Dans la **Vue d’ensemble** d’un groupe, l’état des dépôts est aligné avec le titre.
