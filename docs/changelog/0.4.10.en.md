# Soreno 0.4.10

## Changes

- Codex and Claude quotas no longer refresh while the Soreno window is hidden or minimized; coming back to the window catches up on the missed refresh.
- Codex launched by Soreno again follows the sandbox mode and approval policy of your `config.toml`, including from a Linear issue or in a project group. The folders Soreno opens to it for writing only apply in `workspace-write` mode; in read-only mode, Codex asks before writing.
- On the mobile page, a Pi or OMP session whose history was deleted while the agent is still running shows **Conversation deleted**, without a message field.

## Fixes

- On Windows, reading Codex quotas can no longer force the computer to restart: Soreno lets `codex app-server` exit on its own instead of killing it.
