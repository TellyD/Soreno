# Soreno 0.7.9

## What’s new

### Selection across the whole terminal history

In an agent’s terminal, a selection can span the whole history and stays in place when you scroll or the agent redraws the screen. Dragging past the top or bottom edge scrolls the terminal; double-click selects a word, triple-click a line, Shift+click extends the selection. **Select all** takes the whole history, and **Copy** copies exactly what is selected. Any typing clears the selection.

### Services below the terminal

A project’s services now open in a panel below the terminal, which stays visible and usable. The **Services** button in the status bar, with the number of running services, or `Ctrl+Alt+J` (`Cmd+Option+J` on macOS) opens and closes it; **Escape** closes it. Its height is set by dragging its top border, and its state is remembered for each project.

## Changes

- In **Changes**, a file’s context menu offers **Open file**.
- The diff’s **Show all lines** option is kept from one file to the next and after a restart.
- The active worktree is marked in the primary color in the project list.
- The **Usage** panel no longer shows the plan next to each account’s email address.
- Visual touch-ups: the selected usage card has an outline instead of a fill, a project group’s Git actions are grouped together.
