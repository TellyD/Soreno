# Soreno 0.4.2

## Changements

- La revue IA d’un commit (**Revoir le commit** dans l’historique Git) est retirée. La carte **Git** des paramètres **IA** ne règle plus que le modèle des messages de commit.
- Dans la barre d’icônes, **Projets** prend une icône de maison.

## Corrections

- Quand la description d’une issue Linear est trop longue pour le message de démarrage de l’agent, l’issue complète est jointe en fichier avec toutes ses images : l’agent ne perd plus la fin de la description ni les images qui s’y trouvaient.
- Le titre d’une session Codex ne garde plus le nom de projet tronqué (« ... ») que Codex ajoute quand le nom du dossier est long.
