# Soreno 1.3.8

## What’s new

- The editor shows Linear’s collapsible sections: a block between a `+++ Title` line and a `+++` line appears collapsed under its title, and expands on a click or as soon as the cursor enters it.

## Fixes

- In Chat (OMP), a reply OMP gives before pausing for background work is no longer lost.
- In the editor, an image alone on its line in a list aligns with the item’s text, and a long link label no longer wraps to the next line in the preview.
