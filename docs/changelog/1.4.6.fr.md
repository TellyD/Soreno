# Soreno 1.4.6

## Nouveautés

- Le rail des projets a un menu **Options d’affichage** :
  - **Afficher** choisit les détails visibles sur chaque ligne : **Hôte**, **Branche**, **Projet** et **Résumé des groupes** ;
  - **Regroupement** range les sessions par **Projet** ou par **Statut**, comme la **Vue par priorités**, et le choix est mémorisé ;
  - **Uniquement les projets avec agents** et **Uniquement les sessions actives** filtrent la liste.
- Regroupées par statut, les sessions qui ne sont ni à traiter ni en cours apparaissent dans une section **Inactives**, au lieu d’être masquées.

## Changements

- Dans le menu **Ajouter un projet**, **Nouvelle session** range les projets par section du rail, dans l’ordre du rail.
