# Soreno 0.6.2

## What’s new

- When **Merge into \<main branch\> and delete** stops on a conflict, the notification offers **Resolve with an agent**. Soreno opens a “Conflicts · \<agent\>” session in the worktree, with the agent that was working there, to resolve the conflicts and commit the merge. Then just run the merge again.
- `Ctrl+F` (`Cmd+F` on macOS) searches inside the file open in **Files**, from the editor or the tree: matches are highlighted, a counter shows the current position, `Enter` / `Shift+Enter` move between matches, with the **Match case**, **Match whole word** and **Use regular expression** options.
- Files in **Changes** and in a commit in **History** have a context menu (right-click, Menu key or `Shift+F10`): **Copy relative path**, **Copy absolute path**, **Insert path in active agent** and **Show history** for that file. Paths are relative to the project; a repository file outside the project offers no action.
- Moving a Kanban issue to the in-progress column (In Progress) offers to **Start agent**: it starts in a worktree of the issue’s project. **Not now** moves the issue without an agent. Nothing is offered when an agent is already running on the issue.
- A Kanban issue’s description is edited right in its details, with the note editor (live rendering, `/` commands, pasted images); it saves itself after a typing pause or when leaving the field.
- **Delete comment** removes a comment from a Kanban issue, after confirmation.

## Changes

- The **Files** tree toolbar shows the project path instead of a search field; `Ctrl+P` (`Cmd+P` on macOS) remains the way to find a file. **Refresh files** and **Collapse all** are direct buttons; creating a file or folder goes through the tree’s right-click menu, and **Reveal open file** is gone.
- Claude quotas are read by Claude Code itself (`claude auth status` and `/usage`) instead of its credentials: Soreno no longer accesses `~/.claude/.credentials.json` or the macOS Keychain, and a macOS server now shows its Claude account. Per-model caps use the name Claude Code displays; an expired Claude session is restored with `/login` in Claude Code.
- **Insert path in active agent** no longer shows a notification: the agent is already shown with the path typed in.
- In the project list, worktrees no longer show their path, and the worktree of the active session is marked.
- In **History**, a remote branch tracking a local branch is folded into that branch’s badge instead of a separate badge.
- A project’s name is labeled **Display name** in its form; left empty, it uses the folder name.
- Visual touch-ups: input field background, split pane borders, **History** title aligned with its path filter.

## Fixes

- A Claude Code session stays **working** while agents it launched in the background (subagents, workflows) are still running, instead of switching to waiting as soon as its own turn ends.
- A table in a note preview can again gain a row or a column: **+** buttons appear below and to the right of the table on hover or keyboard focus, and put the cursor in the new cell.
- **Merge into \<main branch\> and delete**, from the project list, merges the worktree’s latest commit, including one made just before, such as the commit resolving a conflict.
