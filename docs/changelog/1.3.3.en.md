# Soreno 1.3.3

## What’s new

- A project group’s Git panel has a **Branches** tab. **Shared** branches show which repositories they are current in and switch all selected repositories at once, skipping those that lack them. **Create and switch** creates a branch in each selected repository. Branches of a single repository stay under it, in **By repository**.
- The project form offers a **Group** field to add the project directly to an existing group on the same machine.

## Changes

- Choosing a project’s environment is simpler: a new SSH project reuses the last saved SSH connection.
- The image button is removed from issue creation: images are pasted or dropped into the description.

## Fixes

- In diffs, line highlights no longer show seams, and those of wrapped fragments no longer stack.
- The segmented control indicator only slides when the selection changes, not when it appears.
