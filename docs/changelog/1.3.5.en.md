# Soreno 1.3.5

## What’s new

- Notifications for a waiting agent give the reason when the agent reports it (**Permission requested**, **Question** or **Sign-in required**) and show the message of its request. A failed turn is notified with **Turn failed**.
- In a project group’s **Branches** tab, each repository opens directly from its row.

## Changes

- A group with disconnected projects says so in all its Git tabs, not only in **Changes**.
- A group’s requests tab keeps its **Pull requests** or **Merge requests** name while its projects are offline, and no longer briefly shows the wrong one for a GitLab project.
- Chat (OMP) is adapted up to OMP 18.22.0.

## Fixes

- On Linux, the AppImage also starts inside a sandbox such as firejail.
- Visual touch-ups: unavailable branch details and the project list scroll bar in a group’s dialog.
