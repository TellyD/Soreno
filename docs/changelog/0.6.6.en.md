# Soreno 0.6.6

## What’s new

### OMP without a terminal

- **New session** > **Chat (OMP)** runs OMP in a conversation view, without a terminal, in local, WSL and SSH projects. Replies stream in as they are written; each tool takes one line that expands to its output or to the diff of an edit.
- OMP’s approvals and questions show above the message box and take one click, or **Enter** and **Esc** on the keyboard. The session is marked as waiting for a reply, like other agents.
- The message box offers the model, with a search by name or provider, the reasoning level, context usage, attachments (images and text files) and a way to stop the current step.
- The conversation resumes when the session restarts. Git panel remarks and Kanban comments sent to the agent reach it directly.
- **Resume a conversation…** in the **…** menu lists the project’s earlier OMP conversations, newest first, with a search, and opens the one you choose in place of the current one, like OMP’s `/resume`.
- Subagents started by OMP show under the call that started them, with what they are doing, their tokens, their duration and a button to stop one.
- OMP’s todo list shows above the message box, with its progress and the current task; it expands to each phase and the state of its tasks.
- OMP must be installed in the project environment; its models, accounts and approvals stay those of its own configuration.

## Changes

- Bold or italic text keeps its code and links: a file name in code inside bold text shows as bold code, without its backticks, in conversations, the Kanban and release notes.
- `mermaid` code blocks show as diagrams, drawn by Mermaid in the light or dark theme’s colors, in conversations, the Kanban, Markdown file previews and release notes. A wide diagram scrolls horizontally; an invalid diagram or a Gantt chart keeps its code.
- An agent can create an issue directly in Linear when you ask it to (“add an issue in Linear”), in the Linear project linked to the session’s project. Otherwise the issue stays local, unless the session is already working on a Linear issue. The **Linear** badge on issues is now colored.
- With colored file icons on, Git changes keep their usual status icons; colored icons now only apply to the explorer and search.
- **Settings › Skills** no longer lists projects whose folder is gone.
- Visual touch-ups: project cards without a selection background, issue creation dialog fields, split terminal icon distinct from the Git panel one, Git files view icon oriented to the layout.

## Fixes

- On macOS, the space bar types a real space in terminals again, instead of a non-breaking space some agents didn’t recognize.
- In an SSH session on a server that isn’t set to UTF-8, which is common from the macOS app, Soreno switches the shell to UTF-8 when the server allows it: an accented prompt or a long line no longer gets garbled when erasing.
