# Soreno 0.3.4

## What’s new

### Linear: images in a new issue

In **New issue**, add images to the description with **Add images**, or by pasting or dropping them into the field. They are uploaded to Linear and inserted into the description at the cursor. Only images are accepted, up to 25 MB each.

## Changes

- **Merge into \<main branch\> and delete** and removing a worktree stop that worktree’s sessions before any Git change. If a session can’t be stopped (lost SSH connection, for example), nothing is changed and the message says so.
- When a merge is still in progress in the source worktree, **Merge into \<main branch\> and delete** explains it and asks you to commit it in Changes, instead of failing with a generic error.

## Fixes

- A project whose folder was deleted no longer keeps the project list from grouping worktrees up to date.
- In Linear descriptions and comments and in assistant replies, an image link no longer shows a `!` before its text.
