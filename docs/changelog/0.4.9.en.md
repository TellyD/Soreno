# Soreno 0.4.9

## What’s new

### What’s new, inside Soreno

The first time Soreno starts after an update, it shows what’s new in that version. Clicking the version number in the status bar opens it again at any time.

### Mobile access: screenshots and agent questions

- The image button, left of the message field, sends a screenshot or photo from the phone to the agent; an image pasted into the field goes the same way (4 MB max).
- When the agent asks a question and waits for your answer, the session shows **Reply expected**, in the session list too, ahead of **Working**.
- A session’s **…** menu offers **Hide tools** to keep only the messages; the choice is remembered on the phone. Tapping a session’s header goes back to the list.

### Markdown preview in the file explorer

In the **Files** tab, **Show Markdown preview** shows a Markdown file rendered, unsaved changes included.

## Changes

- The **Files** tab shows symbolic links with their own icon. They are never followed: not opened or expanded, and can’t be renamed, duplicated or deleted from Soreno.
- Badges of untracked and conflicted files now have a color, like those of added and deleted files.
- On the mobile page, a running session shows **Active**, and an agent at work shows **Working**.

## Fixes

- Codex starts again from a Linear issue or in a project group when it hasn’t approved the project yet.
- In **Settings** > **Skills**, a skill the tool can’t update in place is reinstalled from its source, and a removal that did remove the skill is no longer reported as failed.
