# Soreno 1.3.4

## What’s new

- In the project rail, a repository shows its current branch, and its linked worktrees appear under it with their active sessions. A worktree with a detached HEAD says so, with its folder.

## Changes

- Sub-issues are removed from the Kanban: an issue no longer has a **Sub-issues** section or a **New sub-issue** button. Existing local sub-issues become ordinary issues, without a link to their parent. An issue that had some can now be sent to Linear.
