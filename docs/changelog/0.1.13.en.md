# Soreno 0.1.13

## What’s new

### Pull with rebase

The sync menu in the Git panel now offers **Pull with rebase**, next to **Fetch**, **Pull** and **Push**. Your local commits are replayed on top of the remote branch, without a merge commit.

- Commit or stash your changes before running it: Soreno refuses to rebase a repository with uncommitted changes.
- If an untracked file would be overwritten, Soreno stops before touching the repository.
- If there is a conflict, the rebase is cancelled automatically: your branch goes back to where it was.

## Changes

- When a **Push** is rejected because the remote branch has moved on, Soreno explains why and suggests fetching and integrating those changes before pushing again.
- At launch, the project list shows a single loading indicator until projects and their worktrees are ready, instead of rearranging itself while loading.
- Each project’s branch shows up right at launch, taken from your previous session, then updates.
- Projects in different environments (local, WSL, SSH) now load in parallel: a slow SSH server no longer delays your other projects.

## Fixes

- A terminal opened late or lagging behind now displays completely: Soreno asks the agent to redraw its screen instead of leaving a partial display.
- Long terminal output is displayed faster.
- A slightly shaky click on a session tab no longer moves or splits the tab.
- In the project list, the lines linking a project to its worktrees are better aligned and no longer appear when there is nothing to link.
