# Soreno 0.6.0

## What’s new

### Agent notifications

When a Pi, OMP, Codex or Claude Code agent finishes its turn or waits for a reply, Soreno shows a system notification, unless its terminal is already shown in the focused window. SSH and WSL sessions are covered.

- The notification shows the session, the project and the start of the agent’s last reply, or **Waiting for your reply**. Several sessions reporting at the same time are grouped (**3 sessions need you**). Clicking it brings Soreno to the front on that session.
- An agent waiting for a permission or for the answer to a question is marked **Agent waiting · reply needed**, even while shown, until you reply.
- The Dock badge (macOS) or taskbar icon (Windows) counts unread and waiting sessions.
- **Ctrl+Shift+U** (**Cmd+Shift+U** on macOS) opens the next session waiting for you.
- **Settings** > **General** > **Notifications** > **Agent notifications** turns them off; Soreno then asks the system for no permission.

### Favorite sessions

Right-click a session tab, then **Add to favorites**: closing the tab no longer deletes the session. It can be reopened from the **Favorites** section of its project’s **New session** menu, and resumes its conversation.

### Project icon and color

**Customize icon and color**, in a project’s menu, picks an icon from a catalog of 154, shared with note types, and a color, or imports an image. **Reset** restores the folder icon.

### Comment a diff line in one click

In **Changes**, a **+** appears in the gutter next to the hovered line: click to comment on that line, drag for a range, and Shift+click to extend the selection.

## Changes

- Untracked files are shown with modified files in **Changes**, in the same folders, instead of a separate group.
- The project picker of a Kanban issue shows each project’s environment (local, WSL, SSH).
- **Settings** > **Skills** groups project skills by environment.
- The project list’s view options are now icon buttons in its toolbar.
- The **Stage all** and **Unstage all** buttons fill the available width.
- Alignment touch-ups in the project list and the issue sidebar.

## Fixes

- Crashes and interface errors are recorded in a log, without the content of your notes. On an error, Soreno shows **Reload** instead of a blank window. **Settings** > **General** > **Diagnostics** > **Logs** opens the logs folder, to attach to a bug report.
- When the Claude session has expired, usage says so and suggests opening Claude Code to refresh it, instead of reporting usage as unavailable.
- Over SSH, a request left stuck by a dropped connection is released, and temporary files left on the server are cleaned up on the next connection.
