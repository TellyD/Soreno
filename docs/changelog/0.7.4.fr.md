# Soreno 0.7.4

## Changements

- L’accès mobile est suspendu le temps d’en consolider la sécurité : aucun téléphone ne peut plus joindre un serveur, mais les appairages sont conservés. Le bouton **Mobile** n’apparaît que sur un serveur où le service est déjà installé, et permet seulement de le désactiver.
- Dans le Chat (OMP), `/grill` pose ses questions par tours : chaque tour regroupe les décisions qui peuvent déjà être tranchées, et OMP règle seul les choix évidents en l’annonçant. Quand plusieurs questions arrivent ensemble, un nouveau clic sur l’option choisie laisse une question sans réponse sans perdre les autres.
- Dans le Chat (OMP), une image jointe insère son repère `[Image #N]` à l’endroit du curseur, affiché comme une pastille dans la zone de saisie : le message indique ainsi où chaque image se place. Retirer une image retire son repère et renumérote les suivants.

## Corrections

- Une commande envoyée à un agent juste après la fin de sa session ne produit plus d’erreur : seule la fin de session est signalée.
- L’aperçu d’une image en vignette ne dépasse plus la largeur de la zone de saisie.
