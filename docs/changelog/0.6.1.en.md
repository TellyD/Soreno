# Soreno 0.6.1

## Changes

- `Ctrl+P` (`Cmd+P` on macOS) now lists the files recently opened in **Files** first, marked **Recently opened**, including files ignored by Git such as `.env.local`. With an empty field, it shows these recent files. Soreno remembers the last 50 files opened in each project.
- The summary an agent posts on a Kanban issue now sticks to what changes for the user, without lists of files, tests or commands. After a review or a comment, it only describes what changed since its previous summary.
- Favorite sessions now live behind the **Favorites** icon at the start of the session tabs instead of the **New session** menu. The list gathers the project’s favorites, open or closed: a click shows or reopens the session, and each row can rename it or remove it from favorites.
- While there is no project, **Add project** and **Clone repository** show in the middle of the projects area instead of the Git panel.
- Visual touch-ups: full-width Git history loading button, spacing between project groups and the following entries, mobile page header height.

## Fixes

- When an agent is not installed, its session shows “<agent> is not installed”, with a link to the **Installation guide** and **Retry**, instead of a raw terminal error (such as PowerShell’s on Windows).
- On the mobile page, a conversation shows its first messages as soon as it opens.
