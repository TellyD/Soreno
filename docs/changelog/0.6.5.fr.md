# Soreno 0.6.5

## Nouveautés

### Issues Linear dans le Kanban

- Le Kanban peut afficher, à côté des issues locales, les issues d’une équipe Linear : **Connecter Linear** dans l’en-tête du tableau, avec une clé d’API Linear. Les deux sources partagent les mêmes colonnes ; une issue Linear se reconnaît à son identifiant et au badge **Linear**, et un filtre **Tout / Local / Linear** restreint l’affichage. Sans connexion, le Kanban reste purement local.
- Les modifications faites dans Soreno (état par glisser-déposer, titre, priorité, labels, description, commentaires, suppression) sont faites directement dans Linear. Les changements des collègues apparaissent au retour sur la fenêtre, toutes les 5 minutes tant que le Kanban est affiché, ou aussitôt avec **Actualiser**. Si Linear est injoignable ou refuse la clé, les issues locales restent affichées.
- Une nouvelle issue va par défaut dans la source du filtre (avec **Tout**, la dernière destination choisie) ; la destination reste modifiable à la création, et une sous-issue reste dans la source de sa parente.
- Un agent lancé sur une issue Linear publie son résumé en commentaire Linear et passe l’issue en revue ; une issue qu’il crée va dans la même équipe Linear.
- Un projet Soreno peut être lié à un projet Linear : ses issues Linear apparaissent sous ce projet dans le filtre, et un agent lancé depuis l’une d’elles démarre dans ce projet.
- **Envoyer vers Linear**, dans le détail d’une issue locale, la déplace dans l’équipe Linear affichée, avec ses commentaires repris en fin de description ; la session d’agent liée la suit.

### Passer d’une session à l’autre au clavier

**Ctrl+Tab** affiche l’onglet de session suivant du projet et **Ctrl+Maj+Tab** le précédent, sur macOS comme sur Windows. Une session arrêtée est seulement sélectionnée, pas relancée.

### Icônes de fichiers colorées

**Paramètres › Général › Icônes de fichiers colorées** affiche une icône colorée par type de fichier, issue de Material Icon Theme, dans l’explorateur, les modifications Git, l’ouverture rapide et la recherche. Les modifications Git affichent alors la lettre d’état à côté de chaque fichier. Désactivé par défaut.

### Raccourcis d’édition dans les terminaux des agents

- Sur macOS, les raccourcis de Terminal, iTerm2 et VS Code fonctionnent dans les sessions : ⌘← / ⌘→ vont au début ou à la fin de la ligne, ⌘⌫ efface jusqu’au début et ⌘⌦ jusqu’à la fin, ⌥← / ⌥→ avancent mot par mot, ⌥⌦ efface le mot suivant.
- Sous Windows, Ctrl+Suppr efface le mot suivant.
- ⌘A (macOS) ou Ctrl+Maj+A sélectionne tout le terminal.

## Changements

- **Paramètres › Skills** masque par défaut les projets sans skill, avec l’option **Masquer les projets sans skill**.
- Retouches visuelles : couleurs d’accent sur les contrôles des paramètres et les icônes de skills, interrupteurs plus grands, sélection animée des choix segmentés, dossiers de l’arbre Git colorés avec les icônes de fichiers, fond de la carte d’un projet masqué quand une de ses sessions est active.
