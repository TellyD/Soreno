# Soreno 0.3.2

## Nouveautés

### Épingler des onglets de session

Clic droit sur un onglet de session, puis **Épingler l’onglet** : l’onglet passe en tête, devient plus compact et n’a plus de bouton de fermeture. Un onglet épinglé ne peut pas être fermé ni supprimé tant que vous ne l’avez pas désépinglé. Les onglets épinglés sont conservés au prochain lancement.

### Aperçu des images dans les diffs Git

Quand une image du dépôt est modifiée, le diff affiche l’image avant et après la modification, au lieu du message « Le contenu binaire ne peut pas être affiché. ».

### Linear : plus d’actions depuis Soreno

- **Modifier la description** d’une issue directement dans son détail.
- **Supprimer l’issue** depuis son détail. Elle part dans la corbeille de Linear, d’où vous pouvez la restaurer pendant 30 jours. La session d’agent liée est conservée dans Soreno.
- **Déconnecter Linear** demande maintenant une confirmation.

### Linear : agents en arrière-plan

- Démarrer un agent sur une issue ne vous fait plus quitter le Kanban : l’agent démarre en arrière-plan. Cochez **Ouvrir son terminal une fois démarré** pour y aller directement.
- La carte et le détail de l’issue affichent l’activité de son agent : en cours de travail, en attente de votre réponse, arrêté.
- Fermer la session d’un agent ne la détache plus de son issue : **Rouvrir la session** la relance depuis l’issue.
- Quand la session, son worktree ou son projet a disparu, l’issue indique comment elle s’est terminée (session supprimée, worktree fusionné ou supprimé, projet retiré) et vous pouvez démarrer un nouvel agent.
- Le choix du projet Soreno affiche l’icône, l’environnement (local, WSL, SSH) et le chemin de chaque projet.

## Changements

- Dans les très gros dépôts (plus de 10 000 changements), le panneau Git suspend son actualisation automatique et vous le signale. Cliquez sur **Actualiser** pour relire le dépôt à la demande.
- Quand **Fusionner dans \<branche principale\> et supprimer** échoue, le message en donne la raison précise au lieu d’une erreur générique : opération Git déjà en cours, projet lié injoignable, worktree principal introuvable, etc.
- Le terminal affiché est dessiné avec la carte graphique : il reste fluide pendant les gros affichages.

## Corrections

- Si Claude Code ou Codex ne parvient pas à enregistrer son suivi de conversation (disque plein, serveur distant indisponible…), l’agent continue de fonctionner ; seul le suivi d’activité de ce tour est perdu.
