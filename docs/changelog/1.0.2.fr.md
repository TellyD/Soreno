# Soreno 1.0.2

## Nouveautés

### Issue d’une session dans le panneau de droite

Une session d’agent liée à une issue Kanban affiche un bouton **Issue SOR-N** à côté de **Outils du projet**. L’issue prend alors la place des outils du projet et se modifie comme dans le tableau : statut, priorité, projet, labels, description, commentaires, sous-issues. Les changements apparaissent aussitôt dans le tableau, et **Ouvrir dans le Kanban** y affiche l’issue. Le raccourci `Ctrl+Alt+K` (`Cmd+Option+K` sur macOS) ouvre ou ferme ce panneau, même quand le terminal a le focus.

- Une session sans issue propose à la place **Lier une issue** : choisir une issue ouverte sans agent ou **Créer une issue**. L’issue passe dans In Progress, et l’agent reçoit son titre, sa description et la consigne de compte rendu, comme s’il avait été lancé depuis elle.
- **Délier de cette session** retire le lien après confirmation. L’issue garde son statut et ses commentaires, et l’agent est prévenu.

### Issues Kanban dans les sessions Chat (OMP)

Comme les agents en terminal, une issue Kanban peut lancer une session Chat (OMP) ou lui être liée. Le prompt de l’issue part comme premier message, avec ses images, et le compte rendu de fin de tour est publié sur l’issue. La conversation affiche ce compte rendu sans ses balises.

## Changements

- La section **Skills** des paramètres est retirée, avec la mise à jour et la suppression des skills depuis Soreno.
- Dans la liste du Kanban, la recherche et le bouton de création restent visibles pendant le défilement.

## Corrections

- À la fermeture d’une fenêtre de dialogue ouverte à la souris, l’élément qui l’a ouverte ne s’affiche plus avec le contour de focus clavier. Ce contour revient quand la fenêtre avait été ouverte au clavier.
