# Soreno 1.4.0

## What’s new

### Interactive prototypes in Design

A Design board’s agent can add a little JavaScript to its frames to turn them into interactive prototypes. **Interact with a frame** mode (`I` key) sends clicks to the prototype instead of moving frames; Escape or `I` leaves it, and `T` switches back to element targeting. Scripts load nothing: network, WebRTC and form submission stay blocked, and read-only previews do not run scripts. A coding agent asked to implement the board is told to reproduce its interactions too.

### Board gallery

The **Design** view opens on **All boards**: each board shows as a card with a miniature of its frames, and opens with a click.

### Board reasoning effort

When creating a board, you choose its agent’s reasoning effort, from `low` to `max`, or **Agent default** to keep the CLI’s setting.

### Project skills in groups

A project group’s overview gets access to its projects’ skills: Soreno links them into `.agents/skills` in the group folder, where OMP and Codex find them.
