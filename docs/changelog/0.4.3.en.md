# Soreno 0.4.3

## What’s new

### Built-in chat with your ChatGPT account

New **Chat** session type in the new-session menu: a conversation with Codex in a chat window, with no terminal and nothing to install. It uses your ChatGPT subscription: sign in once with **Sign in with ChatGPT**, or from **Settings** > **Agents**. Codex works in the project folder; on WSL and SSH, its commands and changes run on the project’s machine.

- **Approvals**: by default, Codex asks before each command and each file change (**Allow**, **Allow all in this chat**, **Deny**). **Allow everything** removes these prompts in every chat until you switch back to **Ask for approval**.
- Choose the **Model** and the **Reasoning** level, **Stop** a running step, and add an instruction while it runs.
- A stopped conversation can be picked up again with **Resume the conversation**.

### Start or stop all services

A project’s services all start at once with **Start all**, then stop with **Stop all** once they are all running.

## Changes

- When Soreno starts, SSH projects stay **Not connected** until you use them: no automatic read (branch, Git, files, services, quotas) reaches the server, which avoids waking up a billed remote environment. The last known branch and Git state stay displayed. Starting a session, including from a Linear issue, or clicking **Connect** restores the connection for every project on that server.
- Later summaries from the same agent on a Linear issue (after a review or a commit requested in the session, for example) extend its first comment under a single signature instead of posting a new one. They no longer move the issue.
- The notes AI assistant and its chat are removed. The **AI** settings tab only keeps Codex and the commit message model.
- **Settings** now opens from the bottom of the activity bar instead of the status bar.

## Fixes

- Scrolling a terminal full of colored diffs (OMP sessions in particular) no longer stutters: Soreno moves the existing rows instead of redrawing everything.
