# Soreno 0.3.7

## What’s new

### Comment a diff for the agent

Select lines in the Changes diff or in a project group’s diff, then click **Comment**: write a remark, choose the project’s agent and click **Send to agent** (or Ctrl+Enter). The agent receives the remark with the file, the selected lines and their excerpt at the end of its current turn, without being interrupted. The comment box follows the delivery: **Sent**, then **Delivered**, or **Not delivered** with the reason. If the diff changes in the meantime, Soreno asks you to select the lines again and keeps your text. In a group, the comment goes to the group’s agent.

## Changes

- When Soreno can’t stop the agents of an unreachable SSH server, closing a tab or deleting a project or group offers **Disconnect and delete** instead of failing. Every project using that SSH connection is then disconnected; agents still running on the server may keep running.

## Fixes

- While a long history is written to the terminal (resuming a Pi session, for example), your reading position is kept: you can scroll up with the wheel, Shift+Page Up or the scrollbar without being pulled back to the bottom.
- The terminal looks as it did before 0.3.6 again: correct background, and no more shadow at the top when you scroll back through the history.
