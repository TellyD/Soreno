# Soreno 0.7.1

## Changes

- Mobile access moves: the page now opens at `https://mobile.soreno.dev`, and servers reach the relay by name, `relay.soreno.dev`. On each server already enabled, the **Mobile** dialog offers **Update**; phones then need to be paired once (**Pair a phone**). Traffic stays end-to-end encrypted.
- During a framing (`/grill`), **Revisit** a decision makes OMP ask the question again: the new answer replaces the old one in the **Framing** column, and **Summarize** is offered again after a decision made since the last summary. A skipped question is listed as **Unanswered** without counting as a decision. The summary shows in the conversation, with its **Copy** button.
- During a framing, OMP settles obvious choices on its own and says so, instead of asking a question for each.

## Fixes

- In conversations, numbered lists keep their starting number and indentation.
- A project group’s form no longer offers projects whose folder is missing, unless they already belong to the group.
- The selected Git tab keeps the theme colors.
