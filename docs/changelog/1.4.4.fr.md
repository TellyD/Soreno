# Soreno 1.4.4

## Nouveautés

- L’en-tête d’une issue a un bouton **Copier le nom de la branche git**, qui copie le nom de branche de l’issue et le confirme par une notification.

## Changements

- Le Chat (OMP) est adapté à OMP 19.2 : un formulaire `ask` dont une réponse enfreint une règle peut quand même être envoyé, l’erreur restant signalée. Un champ obligatoire laissé vide n’est signalé qu’une fois le focus passé au champ suivant.

## Corrections

- Renommer une issue locale met aussitôt à jour son nom de branche, ainsi que les autres vues qui l’affichent.
