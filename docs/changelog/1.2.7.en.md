# Soreno 1.2.7

## What’s new

- The Kanban can connect several Linear workspaces, each with its own API key. **Add a workspace…** in the Linear menu connects another one, and each workspace disconnects separately. An agent’s issues go to the workspace linked to its session’s project. The key from a previous version is kept.

## Changes

- A Design board handed to a coding agent is described in an attached `design-board.md` file that lists its screens. The prompt now only points to that file.
- In the **Priority view**, sessions follow the order of the project tree.

## Fixes

- On Linux, closing a tab with a middle click no longer pastes the primary selection into the terminal.
