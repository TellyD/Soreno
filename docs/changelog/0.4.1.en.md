# Soreno 0.4.1

## What’s new

### Activity bar

An icon bar on the left of the window replaces the Notes / Projects switcher: **Projects**, **Kanban** and **Notes** are one click away, with their name on hover. The Linear board opens straight from this bar.

### Unread finished sessions

When an agent finishes its turn while its terminal isn’t shown, its tab and its row in the project list say so (**Agent finished · unread**) until you show its terminal. In a split tab, only the affected pane is marked.

## Changes

- A split tab shows both of its panes: each half of the tab carries its session’s name and can be selected and closed on its own.
- The usage indicator in the status bar shows the used percentage next to its meter.
- In the Git panel, the branch name in the header is no longer a button: branches open from the **Branches** tab.
