# Soreno 1.4.1

## Nouveautés

- Dans les fichiers d’une pull request ou d’une merge request, on peut commenter des lignes du diff et envoyer le commentaire à l’agent en cours, comme dans **Changements**. L’agent reçoit la demande, ses branches et la commande `git diff` à consulter. Depuis la vue d’ensemble d’un groupe, le commentaire précise le dépôt concerné.

## Changements

- Le Chat (OMP) est adapté jusqu’à OMP 19.1 :
  - un formulaire `ask` complet s’affiche et se remplit en une fois, avec la vérification des champs avant l’envoi ;
  - le niveau de réflexion **Auto** est proposé et affiché.
